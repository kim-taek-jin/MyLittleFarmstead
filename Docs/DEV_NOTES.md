# 개발 노트 — 1차 개선 작업

Unity 에디터 없이 작업했습니다. 대신 이렇게 검증했습니다.
- **컴파일:** 스크립트 전체를 Unity 2021.3 참조 어셈블리와 UGUI/TMP/URP API 스텁으로 C# 9 컴파일. 에러와 경고 모두 0개.
- **로직 테스트:** 농장 성장, 시장 가격, 아이템/작물 연결을 콘솔에서 단위 테스트로 확인.

**실제 Unity에서 한 번 열어 아래 체크리스트를 확인해 주세요.**

## 조작법

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 1~5 / 마우스 휠 | 핫바 아이템 선택 (아이템이 5개보다 많으면 휠로 넘김) |
| 왼쪽 클릭 | 도구, 씨앗, 정수 사용 / 다 자란 작물 손으로 수확 |
| 오른쪽 클릭 / F | 들고 있는 음식 먹기 |
| E | 상호작용 (우물, 침대, 상점, 보관함) |
| C | 제작 창 |
| Esc | 열린 창 닫기 |
| F5 / F9 | 저장 / 마지막 저장 불러오기 |
| Ctrl+Shift+N | 저장을 지우고 새 게임 |

자동 저장: 잠들 때(또는 기절했을 때) 저장됩니다.

## 고친 버그

1. 딸기·옥수수·감자 씨앗을 사도 핫바에 안 보여서 심을 수 없던 문제 → 핫바가 `ItemDB` 분류로 표시
2. 무엇을 심든 당근이 수확되던 문제 → 작물마다 데이터(`CropDB`) 분리
3. 씬을 다녀오면 갈아둔 땅, 물 준 땅, 성장 상태가 초기화되던 문제 → 농장 데이터를 `DataManager.farm`에 보관
4. 작물이 실시간 15초마다 자라던 문제 → **물을 준 날 수** 기준 성장으로 변경
5. 보관함에서 아이템이 사라지거나 중복 키 예외가 나던 문제 → 클릭 1개, Shift+클릭 전부 이동
6. 씬 이동 후 핫바 선택이 어긋나던 문제(파괴된 Hotbar 참조) → `Hotbar.Instance` + 선택 기억
7. 핫바 순서가 인벤토리 변경 때마다 바뀌던 문제 → 도구 → 씨앗 → 음식 → 작물 → 정수 고정 순서
8. EventSystem이 없는 씬(Home)에서 클릭하면 NullReference가 나던 문제 → null 체크
9. 흥정 미니게임으로 골드를 무한히 벌던 문제 → 하루 1회, 시장 판매가 보너스로 변경
10. 도구를 1골드에 팔 수 있던 문제 → 도구는 판매 목록에서 제외
11. 게임 오버 후 RESTART를 누르면 체력 0 상태라 바로 다시 게임 오버되던 문제 → 마지막 저장(아침)에서 재시작
12. RESTART 버튼이 파괴된 DataManager를 가리키던 문제(농장으로 돌아온 뒤 버튼 무반응) → 런타임에 다시 연결
13. Farm을 다시 불러오면 생기는 중복 GameManager가 `ItemAssets.Instance`, 시간 매니저를 덮어쓰던 문제
14. 나무, 돌, 사과가 씬에 다시 들어갈 때마다 부활하던 문제 → 하루가 지나야 다시 자람
15. 시장 아이템 오타 `Potaoto Seed` → `Potato Seed` (예전 이름도 자동 변환)
16. 하루가 약 27초였던 문제 → `minutesPerSecond` 45 → 2 (06:00~02:00 하루 ≈ 10분)
17. 배고픔/갈증이 초 단위로 줄어 100초 만에 굶던 문제 → 게임 시간 기준(시간당 5 / 7)
18. 시작할 때 먹을 것이 없던 문제 → 사과 3개 지급, 시장에 빵·사과 추가
19. 침대 태그에 닿기만 해도 자던 중복 로직 제거 (E키로만)
20. 일부 스크립트의 한글 주석이 깨지던 인코딩(CP949) → UTF-8로 통일

## 새 기능

- **마음(Heart) 시스템 + 세상의 채도**: `DataManager.heart`, `WorldColor.cs` (기획서 Pillar 1, 2)
- **하루 평가 요약 화면**: 잠들 때 생활을 평가하고 마음 변화를 보여줌
- **날씨**: 비 오는 날은 밭 자동 물주기, 조명이 어두워짐
- **낮/밤 조명**: Global Light 2D 밝기를 시간대에 따라 조절
- **새벽 2시 기절**: 골드 10% 분실, 마음 −8, 집에서 깨어남
- **물뿌리개 용량**: 기본 10회 / 구리 25회. 우물(E)에서 충전
- **도구 업그레이드**: Fertile Hoe(3칸 갈기), Copper Watering Can(3칸 물주기, 제작 가능), Scythe(주변 3×3 수확)
- **자연의 정수 사용**: Sunshine Shard = 황금 작물(수확량 +1), Earth's Breath = 즉시 하루 성장
- **요리**: 모닥불(Campfire)을 가지고 있으면 Roasted Carrot / Baked Potato / Corn Soup / Strawberry Jam 제작
- **다시 열리는 작물**: Corn, Strawberry는 수확 후 3일마다 다시 열림
- **살아있는 시장**: 오늘의 수요 작물(+50%), 많이 팔면 가격 하락, 흥정 보너스
- **세이브/로드**: `Application.persistentDataPath/save.json`
- **화면 안내 UI(HUD)**: 상단 상태줄, 알림 메시지, 공지 패널. 코드로 자동 생성되므로 씬 작업이 필요 없음
- **임시 아이콘**: 스프라이트가 없는 아이템은 아이템 색 동그라미 아이콘을 자동 생성

## Unity에서 확인할 체크리스트

열기 전에 할 일: 예전에 플레이한 저장이 없으므로 그냥 Farm 씬에서 Play 하면 됩니다.

- [ ] 콘솔에 컴파일 에러가 없는가
- [ ] Farm 씬 Play → 인트로 → GameStart → 조작 안내 공지가 뜨는가
- [ ] **화면이 회색에 가까운가** (채도 −60%). 아니라면 아래 "채도가 안 바뀔 때" 참고
- [ ] 상단 가운데 상태줄(Heart / 날씨 / Water / Holding)이 보이는가
- [ ] 핫바에 Hoe, Watering Can, Scythe, Carrot Seed, Apple이 보이고 1~5와 휠로 선택되는가
- [ ] 괭이로 흙 갈기 → 씨앗 심기 → 물 주기 → 집(Home)에서 잠자기(18시 이후) → 다음 날 작물이 자랐는가
- [ ] 농장 → 시장 → 농장으로 왔을 때 갈아둔 땅과 작물이 그대로인가
- [ ] 우물에서 E → 갈증 회복, 물뿌리개 충전
- [ ] 시장에서 판매 탭: 도구가 안 보이고 가격이 `x개수 가격G`로 표시되는가
- [ ] 흥정 미니게임은 하루 1회만 되는가
- [ ] 게임을 껐다 켜면 마지막으로 잠든 아침 상태로 이어지는가

### 채도가 안 바뀔 때
`WorldColor.cs`는 카메라의 Post Processing을 코드로 켭니다. 그래도 안 보이면:
1. Main Camera → Rendering → **Post Processing** 체크 확인
2. `Assets/Settings/Renderer2D` 에 Post-processing 데이터가 연결되어 있는지 확인 (현재 연결되어 있음)

### 밸런스 조절 (인스펙터에서 바로 변경 가능)
- `GameManager > GameTimeManager > minutesPerSecond`: 하루 길이 (2 = 약 10분)
- `GameManager > DataManager > hungerPerGameHour / thirstPerGameHour`: 배고픔, 갈증 속도
- `GameManager > DataManager > startingHeart`: 시작 마음 (낮을수록 처음 화면이 회색)
- `Grid > CropManager`: 밭일 에너지 소모량
- 아이템 가격, 작물 성장 일수는 `ItemDB.cs`, `CropDB.cs`에서

### 알려진 한계 / 다음에 할 일
- 레시피가 늘어서 제작 창이 넘칠 수 있습니다. `recipeContentParent`에 ScrollRect를 달아 주세요.
- `SampleScene`은 빌드에서 꺼져 있고 수정하지 않았습니다.

## 픽셀 아트 (2차 작업)

모든 게임 그림을 **32×32 픽셀 기준의 통일된 스타일**로 새로 만들었습니다. 같은 팔레트, 자동 외곽선, 왼쪽 위 광원을 씁니다.
- 전체 목록: `Docs/pixelart_preview.png`
- 게임 화면 예시: `Docs/pixelart_scene_mock.png`

| 분류 | 개수 | 내용 |
|---|---|---|
| 아이템 아이콘 | 24 | 도구 5, 씨앗 봉투 4, 작물 4, 음식 7(사과, 빵, 요리 4종), 나무, 돌, 정수 2, 모닥불 |
| 작물 성장 단계 | 16 | 당근, 감자, 옥수수, 딸기 × 4단계 (씨앗 → 새싹 → 성장 → 수확) |
| 땅 타일 | 3 | 흙, 갈린 흙, 젖은 흙 (이어 붙여도 경계가 안 보이는 타일) |
| 월드 오브젝트 | 8 | 나무, 바위, 사과, 우물, 보관 상자, 침대, 출구 표지판, 상인 |
| 플레이어 | 9 | 아래, 위, 옆 × 걷기 3프레임 (왼쪽은 좌우 반전) |

### 어떻게 적용되나 (씬 파일 수정 없음)
- **아이콘:** `ItemAssets`가 `Resources/PixelArt/Items`에서 자동으로 찾습니다. 우선순위는 Extra Sprites → 픽셀 아트 → 예전 그림 → 임시 아이콘 순입니다.
- **작물:** `Crop`이 작물 ID별 성장 스프라이트를 불러와 밭 한 칸 크기에 맞춥니다.
- **타일:** `Assets/Tiles/*_Tile.asset`이 새 타일 스프라이트를 쓰도록 바꿨습니다. 예전의 갈색 사각형 GameObject는 더 이상 생성되지 않습니다.
- **월드 오브젝트:** `PixelArtWorld`가 씬이 열릴 때 원래 그림을 숨기고, 같은 위치와 크기에 픽셀 아트를 겹쳐 그립니다. 콜라이더와 스크립트는 그대로입니다.
- **플레이어:** `PlayerPixelAnimator`가 자동으로 붙어서, 이동 방향에 따라 걷기 애니메이션을 재생합니다.
- **예전 그림으로 되돌리기:** `GameManager > ItemAssets > Use Pixel Art` 체크 해제 (타일은 git으로 되돌리기)

### 그림 수정 / 추가하는 법
그림은 손으로 찍은 PNG가 아니라 **코드로 그립니다.** `Tools/pixelart/`의 파이썬 파일을 고친 뒤 실행하면 PNG와 Unity 설정(.meta)이 다시 만들어집니다.
GUID가 경로 기준으로 고정이라, 다시 만들어도 Unity 연결은 끊기지 않습니다.

```bash
pip install pillow
```

```bash
python3 Tools/pixelart/generate.py
```

```bash
python3 Tools/pixelart/mockup.py
```

| 파일 | 내용 |
|---|---|
| `pixel.py` | 팔레트, 도형, 명암, 자동 외곽선 도구 |
| `items.py` | 아이템 아이콘 |
| `crops.py` | 작물 성장 단계, 땅 타일 |
| `world.py` | 월드 오브젝트, 플레이어, 상인 |

- **새 아이템 아이콘:** `items.py`의 `ITEMS`에 `'아이템_이름': 함수`를 추가하면 됩니다. 키는 아이템 이름을 소문자로 바꾸고, 공백은 `_`로, 따옴표는 빼서 만듭니다. 예) `Earth's Breath` → `earths_breath`
- **새 작물:** `crops.py`의 `CROPS`에 4단계 함수를 추가하고, `CropDB.cs` / `ItemDB.cs`에 등록하면 됩니다.
- Aseprite 같은 툴로 직접 그린 그림으로 바꾸고 싶으면, 같은 이름의 PNG(32px)를 덮어쓰면 됩니다.

### Unity에서 확인할 것 (픽셀 아트)
- [ ] 핫바, 상점, 보관함, 제작 창 아이콘이 새 그림으로 보이는가
- [ ] 밭의 흙, 갈린 흙, 젖은 흙 타일이 새 그림인가 (갈색 사각형이 사라졌는가)
- [ ] 작물이 밭 한 칸 크기로 보이고, 단계별로 그림이 바뀌는가
- [ ] 나무, 바위, 사과, 우물, 상자, 침대, 출구, 상인이 새 그림으로 바뀌고 위치가 자연스러운가
- [ ] 플레이어가 걸을 때 방향별 애니메이션이 나오는가
- [ ] 크기가 어색하면: `PixelArt.Overlay`의 `fill`(기본 0.9) 값이나 오브젝트 Scale을 조절

### 배경 (3차 작업)
배경 5장(농장, 집, 시장, 흥정 미니게임, 회색 도시)도 픽셀 아트로 새로 그렸습니다. `Tools/pixelart/backgrounds.py`
- **같은 픽셀 밀도:** 배경도 32px = 1유닛이라, 캐릭터·작물·타일과 픽셀 크기가 같습니다. 크기가 섞이지 않는 것이 "AI 그림 같지 않게" 보이는 핵심입니다.
- **실제 배치 기준 구도:** 씬의 실제 좌표에 맞춰 그렸습니다. 밭 타일 영역, 집 포털(왼쪽 아래 → 오두막 문), 시장 포털(오른쪽 아래 → 표지판), 흥정 포털(위 → 나무 아치), 우물로 가는 길, 침대·출구 문·상인 노점 위치 등.
- **의도적인 배치:** 무작위 노이즈 대신 반복 타일(잔디 3종)과 손으로 정한 디테일(꽃 무리, 연못, 울타리, 우편함, 장작더미)을 씁니다. 광원은 모두 왼쪽 위입니다.
- **적용 방식:** `PixelArtWorld`가 예전 배경 위에 같은 크기로 정확히 겹쳐 그립니다. 나무는 1.45배로 키우고 밑동을 고정해서 플레이어보다 크게 보입니다.
- **미리보기:** `Docs/pixelart_bg_*.png`, 오브젝트를 배치한 농장 장면은 `Docs/pixelart_bg_farm_scene.png`
- **실제 오브젝트를 올려 보는 미리보기:** `python3 Tools/pixelart/scene_preview.py 출력.png`

### 흥정 장면 / 캐릭터 다시 그리기 (4차 작업)
- **상인 (`Tools/pixelart/haggle.py`):** 도형 명암을 빼고, 픽셀 지도에 한 점씩 직접 찍었습니다. 왼쪽 절반을 그린 뒤 좌우를 맞추고, 귀 뒤 연필이나 주머니 연필 같은 비대칭 디테일을 따로 넣었습니다.
- **명암:** 왼쪽 위 광원 기준으로 경계가 딱 끊기는 3단계 셀 셰이딩만 씁니다. 외곽선은 짙은 갈색 하나로 통일했습니다.
- **흥정 장면:** 절반 해상도로 그린 뒤 화면 전체를 2배로 키웠습니다. 클로즈업이라 픽셀이 더 크지만, 한 화면 안에서는 픽셀 크기가 같습니다.
- **소품:** 똑같은 것을 반복하지 않고 하나씩 다르게 배치했습니다. 자는 고양이, 마늘 다발, 달력, 칠판 가격표, 장부와 깃펜, 동전 더미, 저울, 종, 앞쪽의 과일 상자와 자루.
- **시장 상인:** 같은 디자인으로 작게 다시 그렸습니다.
- **플레이어 (`Tools/pixelart/characters.py`):** 9프레임 모두 같은 방식(픽셀 지도 + 같은 외곽선)으로 다시 그려서, 상인과 같은 게임 캐릭터처럼 보입니다.

## 회색 주민 시스템 + 새 콘텐츠 (5차 작업)

미리보기: `Docs/villagers_market_preview.png`, `Docs/villagers_stages.png`

### 회색 주민
마을 주민들도 주인공처럼 색을 잃었습니다. 소원을 하나 들어줄 때마다 색이 1/3씩 돌아오고, 3개를 모두 들어주면 완전히 컬러가 됩니다.

| 주민 | 위치 | 소원 1 | 소원 2 | 소원 3 |
|---|---|---|---|---|
| **Grandma Rosa** (빵집 할머니) | 시장 빵집 앞 | 당근 3 → 빵 3 + **당근 케이크 레시피** | 옥수수 2 + 사과 2 → 150G | 딸기잼 1 → 300G + 당근 케이크 2 |
| **Theo** (대장장이) | 시장 도구점 앞 | 나무 10 → **구리 물뿌리개 레시피** | 돌 15 → 200G + 비옥한 괭이 | 햇빛 조각 + 대지의 숨결 → 500G |
| **Mina** (아이) | 농장 연못가 | 사과 2 → **낚싯대 (낚시 해금)** | 잉어 1 → 딸기 씨앗 3 | 햇빛 조각 + 딸기 2 → 해바라기 씨앗 5 + **시장 판매 해금** |

- **처음 만날 때:** 사연과 첫 소원을 이야기합니다. 머리 위에 `!` 말풍선이 뜨면 할 이야기가 있거나 소원 아이템을 가지고 있다는 뜻입니다.
- **아이템 전달:** 다 모았으면 E로 대화하고 `[Y] Give`를 누르면 됩니다. 보상, 마음 상승, 색 회복 연출이 나옵니다.
- **정의 파일:** `VillagerDB.cs` (대사, 소원, 보상). 새 주민을 추가하려면 여기에 한 명 추가하고, `Tools/pixelart/villagers.py`에 그림을 추가하면 됩니다.
- **배치:** `WorldSpawner.cs`가 씬이 열릴 때 코드로 배치합니다. 씬 파일 수정이 필요 없습니다.

### 새 콘텐츠
- **낚시:** 농장 연못 근처에서 E → 기다렸다가 `!!`가 뜨면 바로 E. 미나에게 받은 낚싯대가 필요합니다.
  - Minnow 15G, Carp 45G, Golden Koi 300G (마음이 높을수록 잘 잡힘), 가끔 Old Boot
- **요리 추가:** 생선구이(작은 물고기 또는 잉어 + 나무), 당근 케이크(당근 2 + 빵). 둘 다 모닥불과 해금이 필요합니다.
- **해바라기:** 5일 성장, 90G. 수확할 때마다 마음 +2.
- **도시에서 온 편지:** 4일째와 10일째 아침에 옛 상사의 제안이 옵니다.
  - 수락하면 골드를 얻지만 마음이 크게 깎입니다 (400G / −12, 1500G / −25).
  - 거절하면 마음이 오릅니다. 10일째 편지를 찢으면 엔딩 문구가 달라집니다.
- **생활 일지 (J):** 마음, 골드, 주민별 진행도와 현재 소원, 잡은 물고기 도감.
- **엔딩:** 주민 3명 모두 색을 되찾고 마음이 90 이상이면 "Happiness, rebuilt" 엔딩이 나옵니다. 그 뒤에도 계속 플레이할 수 있습니다.
- **대화 UI:** 아래쪽 대화 상자에 초상화, 이름, 대사가 나옵니다. `[E]`로 넘기고 `[Y]`/`[N]`으로 선택합니다. HUD가 코드로 만듭니다.

### 바뀐 점
- 구리 물뿌리개 레시피는 이제 처음부터 보이지 않고, 테오의 첫 소원을 들어줘야 열립니다.

### Unity에서 확인할 것

- [ ] E로 대화 → 대화 상자 → 아이템을 모아서 다시 E → `[Y] Give` → 색이 1/3 돌아오는가

- [ ] 4일째 아침 편지 선택지(Y/N)가 뜨는가
- [ ] J로 일지가 열리고 닫히는가
- [ ] 저장하고 다시 켜도 주민 진행도가 유지되는가

## 색을 먹는 정령 + 나눔 → 별의 언덕 (6차 작업)

시장놀이(조이월드)의 "새끼 용 키우기"와 "선행점수 → 하늘나라"를 이 게임의 주제에 맞게 바꿨습니다. 이름, 캐릭터, 그림은 가져오지 않았고 구조만 참고했습니다.
미리보기: `Docs/spirit_starhill_preview.png`

### 색을 먹는 정령
- **등장:** 처음으로 Sunshine Shard나 Earth's Breath를 얻으면 회색 아기 정령이 나타나 따라다닙니다.
- **먹이기 (G):** 들고 있는 아이템을 먹입니다. 4가지 색 기운이 쌓입니다.

| 색 | 먹이 | 능력 (어린 정령 / 다 큰 정령) |
|---|---|---|
| 햇빛 | Sunshine Shard +3, Sunflower +2, Corn +1 | 최대 에너지 +10% / +20% |
| 대지 | Earth's Breath +3, Carrot·Potato +1 | 물 준 작물이 밤사이 하루 더 자랄 확률 10% / 20% |
| 물 | Minnow +1, Carp·Grilled Fish +2, Golden Koi +5 | 황금 잉어 확률 +2% / +4%, 입질 시간 +0.2초 / +0.4초 |
| 꽃 | Apple·Strawberry +1, Strawberry Jam +3, Carrot Cake (대지 +1, 꽃 +2) | 매일 아침 마음 +1 / +2 |
| 전부 | **Star Fragment** (네 색 모두 +1) | 별의 언덕에서 주움 |

- **성장:** 경험치 8에서 어린 정령, 25에서 다 큰 정령이 됩니다. 가장 많이 먹은 색으로 모습이 정해집니다.
- **프리즘:** 다 큰 정령이 네 색을 고르게 먹으면(가장 적은 색이 가장 많은 색의 절반 이상) 희귀한 **프리즘** 정령이 되고, 모든 능력을 조금씩 받습니다.
- **도감:** 모습은 10가지입니다. 다른 색을 먹여 언제든 바꿀 수 있고, 만난 모습은 일지(J)에 기록됩니다. 새 모습을 만나면 마음 +2.
- **관련 파일:** `SpiritDB.cs` (먹이, 단계, 모습, 능력), `Spirit.cs` (따라다니기, 먹이기)

### 나눔 → 별의 언덕
- **나눔 상자:** 시장에 생겼습니다. 작물, 음식, 물고기를 들고 E로 1개, Shift+E로 필요한 만큼 나눕니다.
  - 나눔 점수는 개당 판매가의 1/10 (최소 1)이지만, **하루 최대 5점**까지만 받습니다. 비싼 것을 몰아 내도 하루 5점입니다.
  - 상한에 닿으면 그날은 아이템을 받지 않습니다 ("내일 또 와 주세요"). 점수 없이 아이템만 사라지지 않습니다.
  - 주민 소원을 들어주면 +3 (상한 없음). 하루 첫 나눔은 마음 +2.
- **별의 언덕:** 나눔 점수가 **60**이 되면 열립니다. 가장 빨라도 나눔 상자만으로 12일, 주민 소원 9개를 모두 들어줘도 7일이 걸립니다. 보통은 15~20일째쯤 열립니다. 맑은 밤(20시 이후, 비 안 옴)에 농장 오른쪽 위에 빛나는 덩굴이 자랍니다.
  - 덩굴 앞에서 E를 누르면 언덕으로 올라갑니다.
  - 밤마다 별 조각이 최대 10개 떨어지고, 걸어서 닿으면 줍습니다.
  - 벤치에서 E를 누르면 별을 봅니다. 밤마다 한 번 마음 +3.
  - 아래쪽 덩굴에서 E를 누르면 농장으로 내려갑니다.
- **구현 방식:** 언덕은 Farm 씬 안의 멀리 떨어진 곳(y +100)에 코드로 만들고, 올라가면 카메라를 옮겨서 보여줍니다. 새 씬 파일은 필요 없습니다.
- **관련 파일:** `DonationBox.cs`, `StarHill.cs`, `DataManager.AddKindness`

- [ ] 정수를 처음 주우면 정령이 나타나 플레이어를 따라다니는가 (크기와 위치가 자연스러운가)
- [ ] G로 먹이면 색 기운이 오르고, 단계나 색이 바뀔 때 모습이 바뀌는가
- [ ] 시장 나눔 상자에서 E로 나누면 점수가 오르고, 하루 5점에서 멈추며, 60이 되면 안내가 뜨는가

## 마음의 계절 + 내일 예고 + 계절 앨범 + 데모 모드 (7차 작업)

미리보기: `Docs/heart_seasons_preview.png`

### 마음의 계절
달력이 아니라 **마음(Heart)이 계절을 정합니다.** 게임은 겨울(번아웃)에서 시작합니다.

| 마음 | 계절 | 새로 자라는 작물 |
|---|---|---|
| 0~29 | 겨울 | 당근, 감자 |
| 30~59 | 봄 | 딸기 |
| 60~84 | 여름 | 옥수수, 해바라기 |
| 85~ | 가을 | **호박** (새 작물, 호박 파이 레시피 해금) |

- **바뀌는 때:** 아침(잠에서 깬 직후)에만 바뀝니다. 계절이 오면 큰 안내 화면이 뜹니다.
- **꽃샘추위:** 다시 무리해서 그 계절 기준보다 마음이 5 넘게 떨어지면 한 계절 돌아갑니다.
- **작물:** 계절이 돌아가도 **시들지 않습니다.** 그 계절에 안 맞는 작물은 성장만 멈추고, 계절이 돌아오면 다시 자랍니다.
- **심기와 시장:** 지금 계절에 안 맞는 씨앗은 심을 수 없고, 시장에서도 팔지 않습니다. 오늘의 수요 작물도 제철 작물 중에서 고릅니다.
- **날씨:** 마음을 따라갑니다. 전날 마음이 +6 이상이면 비 확률이 절반, 전날 마음이 줄었으면 +30%입니다.
  - 겨울에는 비 대신 **눈**이 옵니다. 눈은 밭을 적시지 않습니다.
- **그림:** 농장과 시장 배경이 계절마다 바뀝니다.
  - 겨울: 눈 덮인 땅, 언 연못, 눈사람, 지붕 위의 눈
  - 봄: 꽃이 핀 덤불
  - 여름: 진한 녹음
  - 가을: 단풍, 낙엽, 호박
  - 나무, 바위, 우물, 상자, 표지판도 겨울엔 눈이 쌓이고, 나무는 가을에 노랗게 물듭니다.
- **비·눈 효과:** 야외(농장, 시장)에서 화면에 비와 눈이 내립니다 (`WeatherFX.cs`).
- **주민 대사:** 계절마다 다른 한마디가 있습니다.
- **관련 파일:** `SeasonSystem.cs` (기준값, 날씨 확률)

### 내일 예고
아침 요약 화면 맨 아래에 **"Today"** 줄이 붙습니다 (최대 3개). 예를 들면:
- 다 익은 작물 수
- "물을 주면 내일 익을 작물 N개"
- "봄까지 마음 N"
- "○○의 소원 아이템을 다 가지고 있어요"
- "오늘 밤 맑음: 별 덩굴이 자랍니다"
- "앨범에 남은 사진 N장"

### 계절 앨범 (P)
- 계절마다 사진 6장, 총 24장입니다. 조건을 달성하면 회색 실루엣이 컬러 사진으로 바뀝니다.
  - 예: 첫 당근 수확, 처음 낚은 물고기, 별의 언덕 방문, 황금 잉어
- **찍을 수 있는 때:** 그 계절이 왔거나 이미 지나간 뒤에만 찍을 수 있습니다. 지나간 계절의 사진도 나중에 찍을 수 있습니다 (놓쳐서 아쉬운 일 없음).
- **보는 법:** 못 찍은 사진엔 힌트가 보입니다. 아직 오지 않은 계절의 페이지는 "???"로 보입니다.
- **보상:** 한 계절 페이지를 다 채우면 300G와 마음 +5. 24장을 모두 모으면 특별 메시지가 나옵니다.
- **조작:** ←/→ 로 계절 페이지를 넘기고, P 또는 Esc로 닫습니다. 앨범을 여는 동안 플레이어는 움직이지 않습니다.
- **관련 파일:** `AlbumDB.cs` (사진 목록, `Album.Report`)

### 데모 모드
- **켜는 법:** `GameManager > DataManager > Demo Mode` 체크, 또는 Player Settings의 Scripting Define Symbols에 `DEMO_BUILD`를 추가합니다.
- **동작:** 마음이 봄 기준(30)에 닿는 아침에 "봄이 오고 있어요... 데모를 플레이해 주셔서 감사합니다" 화면이 뜹니다. 그 화면에서 Enter를 누르면 `Wishlist Url`(Steam 페이지)이 열립니다.
- **데모 종료 뒤:** 계절은 겨울에 머물고, 계속 플레이는 할 수 있습니다.

### Unity에서 확인할 것
- [ ] 새 게임이 겨울(눈 덮인 농장)로 시작하는가
- [ ] 마음이 30이 된 다음 아침에 "Spring has come" 화면과 함께 배경이 봄으로 바뀌는가
- [ ] 겨울에 딸기 씨앗을 심으면 안내가 뜨고, 시장에서 제철 씨앗만 파는가
- [ ] 비 또는 눈이 내리는 날 화면에 비·눈이 보이는가
- [ ] 아침 요약에 Today 줄이 나오는가
- [ ] P로 앨범이 열리고, 사진을 찍으면 알림과 함께 컬러로 바뀌는가
- [ ] Demo Mode를 켜면 봄 직전에 데모 종료 화면이 뜨는가
- [ ] 예전 저장 파일을 불러와도 문제가 없는가 (계절은 다음 아침에 마음에 맞게 정해짐)

## 브라우저 미리보기 (`Tools/webpreview/`)

Unity 없이 게임을 볼 수 있게, 같은 픽셀 아트와 규칙을 자바스크립트로 옮긴 웹 미리보기입니다. Unity 게임과는 별도로 만든 것이라 세부 동작은 조금 다를 수 있습니다.

- **구성:**
  - `game.js`: 게임 규칙 (아이템, 작물, 주민, 정령, 마음의 계절, 앨범, 낚시, 나눔, 별의 언덕, 흥정, 편지)
  - `template.html`: 화면, 조작 안내, 미리보기 도구 버튼
  - `build.py`: `Assets/Resources/PixelArt`의 그림을 전부 한 HTML 파일에 넣어 줍니다
- **다시 만들기:** `python3 Tools/webpreview/build.py 출력.html`
- **미리보기 도구:** 마음 +10, 하루 넘기기, 아이템 받기, 별의 언덕 열기, 밤으로, 4배속, 새로 시작. 계절 변화를 빨리 확인할 수 있습니다.

### 크기 / 밭 수정 (미리보기 피드백 반영)
- **크기:** 캐릭터, 주민, 정령, 나무, 바위, 우물, 상자, 침대, 상인을 모두 **배경과 같은 픽셀 크기(32px = 1유닛)**로 그립니다. 예전에는 원래 그림 크기에 맞춰 거의 2배로 그렸습니다. 이제 캐릭터 키는 밭 한 칸 정도입니다.
  - 구현: `PixelArt.Overlay(..., native: true)`, `PixelArt.CharacterScale = 1`
- **밭 테두리:** 밭 둘레에 흙 테두리를 배경에 그렸습니다. 겨울엔 눈이 쌓입니다.
- **갈린 흙 타일:** 칸마다 둥근 이랑(흙 둔덕)으로 다시 그려서 칸이 하나씩 구분됩니다.
- **맨흙 타일:** 점박이를 줄였습니다.
- **바닥 사과:** 작은 16px 사과 그림을 새로 그렸습니다.
- **Unity에서 확인할 것:** 콜라이더와 트리거(우물, 침대 등)는 예전 큰 그림 기준 크기라서, 그림보다 범위가 넓게 느껴질 수 있습니다. 어색하면 알려주세요.

## 맵 확장 1·2단계: 맵 기반 + 넓어진 농장과 개간 (8차 작업)

농장이 **화면 4장 크기(36×20칸)**로 넓어졌습니다. 예전 농장은 북서쪽에 같은 좌표 그대로 있어서 밭, 집, 우물, 연못, 흥정 문이 모두 그대로 동작합니다.

### 맵 데이터
- **파일:** `Assets/Resources/Maps/farm.json`
  - 만드는 스크립트: `Tools/maps/make_farm_map.py`
  - 한 글자가 한 칸(1유닛 = 32px)입니다. `. 잔디  = 길  x 빈 흙  g 잡초  k 그루터기  o 바위  T 나무  r 돌  a 사과  * 꽃  ~ 예전 농장`
  - 출구(`exits`)는 월드 좌표 사각형입니다. `locked`에는 그 길을 여는 마음의 계절을 적습니다.
  - `arrivals`는 다른 씬에서 농장으로 올 때 도착하는 위치입니다.
- **그림:**
  - `Tools/pixelart/farmmap.py`가 같은 파일을 읽어 `bg_farmmap_<계절>` 4장(1152×640)을 그립니다.
  - 예전 농장 그림 코드(`backgrounds.farm`)를 그대로 재사용하고, 길과 울타리 덤불만 늘렸습니다.
  - 미리보기: `Docs/pixelart_bg_farmmap_*.png`
- **맵을 고치려면:** `make_farm_map.py` 수정 → `python3 Tools/maps/make_farm_map.py` → `python3 Tools/pixelart/generate.py`

### 넓어진 농장 구성
- **큰 길:** 동쪽으로 이어지고, 길 끝(x 26.3~27)이 시장 출구입니다. 예전 시장 포털은 실행 중에 길 끝으로 옮겨집니다.
- **묵은 밭 (남동쪽 18×7칸):** 잡초 65, 그루터기 15, 바위 10개가 있습니다. 모퉁이 6칸은 처음부터 비어 있어 바로 갈 수 있습니다.
- **동쪽 초원, 남서쪽 들판:** 새 나무, 돌, 사과가 있습니다. 씬의 자원 프리팹을 복제한 것이라 채집 규칙과 다음 날 다시 자라는 규칙이 같습니다.
- **잠긴 길 두 곳:** 회색 가시덤불이 막고 있고, 부딪히면 표지판 말이 나옵니다.
  - 서쪽 숲길: 봄에 열림 (3단계)
  - 남쪽 언덕길: 가을에 열림 (4-2단계, 노을 언덕. 처음 계획했던 옛 기차역은 스타듀밸리와 비슷해서 바꿨습니다)
  - 길 너머 지역은 아직 만들지 않았습니다. 지금은 계절이 와도 "곧 열린다"는 말만 나옵니다.

### 개간
| 대상 | 도구 | 횟수 (좋은 괭이) | 한 번에 에너지 | 얻는 것 |
|---|---|---|---|---|
| 잡초 | 낫 또는 괭이 | 1 | 2 | 없음 |
| 그루터기 | 괭이 | 3 (2) | 4 | 나무 2 |
| 바위 | 괭이 | 4 (3) | 4 | 돌 2, 가끔 대지의 숨결 |

- 전부 치우는 데 에너지 약 470이 들어서, 농사와 함께 하면 며칠이 걸립니다.
- 치운 칸은 바로 갈 수 있는 흙이 되고, `FarmData.clearedDebris`에 저장되어 다시 생기지 않습니다.
- 25%마다 진행도를 알려 주고, 다 치우면 마음 +5입니다.
- 그루터기와 바위는 지나갈 수 없고, 잡초는 밟고 지나갈 수 있습니다.

### 카메라
- 농장에서는 카메라가 플레이어를 따라가고, 맵 밖은 보이지 않습니다.
- 플레이어는 맵 밖으로 나갈 수 없습니다.
- 카메라는 픽셀 격자(1/32유닛)에 맞춰 움직여서 그림이 떨리지 않습니다.
- 별의 언덕에 올라가 있는 동안에는 따라가기를 멈춥니다.

### 새 스크립트 / 바뀐 스크립트
- **새 스크립트:**
  - `MapData.cs`: 맵 JSON 읽기
  - `FarmMap.cs`: 농장 씬이 열릴 때 바닥 그림, 흙 타일, 개간 대상, 자원, 출구, 카메라, 도착 위치를 설정
  - `Debris.cs`: 잡초, 그루터기, 바위
  - `CameraFollow.cs`: 플레이어 따라가기와 맵 경계
  - `LockedExit.cs`: 가시덤불로 막힌 길
- **바뀐 스크립트:**
  - `PixelArtWorld`: 맵이 있으면 `BackGroundFarm`을 큰 그림으로 교체. 복제한 자원용 `ApplyTo` 추가
  - `PlayerAction`: 클릭한 칸에 개간 대상이 있으면 먼저 처리
  - `FarmData`: `clearedDebris` 추가
  - `DataManager`: `IsResourceCleared` 추가
  - `HaggleGame`: 흥정이 끝나면 북쪽 문 앞으로 돌아옴
- **씬 파일은 고치지 않았습니다.** `farm.json`을 지우면 예전 한 화면 농장으로 돌아갑니다.

### Unity에서 확인할 것

## 맵 확장 3단계: 숲 입구 (9차 작업)

마음이 **봄(30)**이 된 다음 아침, 농장 서쪽 숲길의 회색 가시덤불이 꽃 아치로 바뀌고 숲이 열립니다. 한 번 열린 길은 꽃샘추위로 겨울이 돼도 닫히지 않습니다. 데모 모드는 봄 직전에 끝나므로 숲은 정식판 콘텐츠입니다.

미리보기: `Docs/forest_preview.png` (되살린 북쪽 빈터만 컬러), `Docs/pixelart_bg_forest_*.png`

### 숲의 구성 (`Assets/Resources/Maps/forest.json`, 30×20칸)
- 만드는 스크립트: `Tools/maps/make_forest_map.py`
- 글자: `# 나무  ~ 개울  b 다리  = 길  - 빈터  . 숲 바닥  c 묘목 자리  O 큰 나무  w 샘  s 샘가 그루터기  f 채집 자리  L 쓰러진 통나무  B 덤불`
- 동쪽 입구 → 다리 → 가운데 큰 나무 광장 → 북쪽, 서쪽, 남쪽 빈터
- 남쪽 빈터와 남동쪽 공터는 쓰러진 통나무로 막혀 있어서 곡괭이가 있어야 갈 수 있습니다.
- Unity에서는 별의 언덕처럼 **농장 씬 안 멀리(x 190~220)**에 실행 중에 만듭니다. 꽃 아치에 들어가면 순간이동하고 카메라 범위가 숲으로 바뀝니다. 새 씬 파일은 없습니다.

### 숲 되살리기
- 숲은 짙은 회색 그림으로 시작합니다.
- 빈터의 조약돌 원에 도토리를 심고, 매일 물을 주면 한 단계씩 자랍니다. 비 오는 날은 저절로 물을 준 것으로 칩니다.
  - 도토리 → 새싹 → 묘목 → 어린 참나무 (물 준 날 3번)
- 어린 참나무가 되면 그 빈터 둘레에 색이 돌아오고 마음이 3 오릅니다.
- 3곳을 모두 되살리면 큰 나무가 깨어나 꽃을 피우고, 숲 전체가 컬러가 되며, 마음이 5 오릅니다.
- **구현:** 계절마다 컬러 그림(`bg_forest_<계절>`)과 회색 그림(`bg_forest_gray_<계절>`)을 겹쳐 놓습니다.
  - 컬러 그림은 `SpriteMask`(둥근 디더링 가장자리, `forest_mask`) 안에서만 보입니다.
  - 큰 나무가 깨어나면 마스크 없이 전부 보입니다.
  - 마음에 따른 세상 전체의 채도 변화는 그대로 함께 적용됩니다.

### 채집
- 아침마다 채집 자리 16곳 중 몇 곳에 생기고, 걸어서 닿으면 줍습니다.
- 개수: 마음 0~24는 3개, 25~49는 4개, 50~74는 5개, 75~99는 6개, 100은 7개입니다. 꽃샘추위로 겨울이면 마음과 상관없이 2개입니다.
- 종류: 달래(Wild Garlic) 45%, 고사리(Fern Sprout) 35%, 곰보버섯(Morel) 20%
- 빈 묘목 자리가 있고 가방에 도토리가 없으면, 그날 한 곳은 도토리가 나옵니다.
- **새 요리:**
  - 봄나물 무침 (Spring Greens): 달래 1 + 고사리 1 (모닥불 필요 없음)
  - 곰보버섯 수프 (Morel Soup): 곰보버섯 2 + 달래 1 (모닥불 필요)
  - 둘 다 숲이 열리면 제작 목록에 나옵니다.
- 정령 먹이: 달래는 꽃, 고사리와 곰보버섯은 땅 색입니다.

### 샘가 쉼터
- 샘가 그루터기에서 E를 누르면 하루 한 번 마음이 2 오릅니다.
- 언제든 샘물을 마실 수 있고 물뿌리개도 채울 수 있습니다.
- 큰 나무 앞에서 E를 누르면, 잠들어 있을 때는 되살린 빈터 수와 함께 힌트가 나옵니다.

### 곡괭이 (Mattock)
- 시장에서 150G에 사거나 (가지고 있지 않을 때만 팔아요), 나무 5 + 돌 5로 만들 수 있습니다.
- 그루터기는 2번, 바위는 3번, 숲의 통나무는 3번 쳐야 하고, 한 번에 에너지 4가 듭니다.
- 이제 그루터기와 바위는 괭이로 치울 수 없습니다. 괭이는 땅 가는 일만 합니다.
- 잡초는 그대로 낫이나 괭이로 치웁니다.
- 묵은 밭을 전부 치우는 데 드는 에너지는 약 370입니다.

### 새 스크립트 / 바뀐 스크립트
- **새 스크립트:**
  - `ForestState.cs`: 저장되는 숲 상태와 규칙 (유니티 없이 테스트 가능)
  - `ForestArea.cs`: 숲 만들기, 묘목, 채집물(`ForagePickup`), 쉼터, 큰 나무
  - `AreaPortal.cs`: 같은 씬 안 지역 이동
- **바뀐 스크립트:**
  - `ItemDB`: 곡괭이, 도토리, 채집물 3종, 요리 2종
  - `Craftingmanager`, `Shop`, `SpiritDB`: 새 아이템 반영
  - `Debris`: 곡괭이 규칙, 통나무
  - `FarmMap`: 숲이 열리면 꽃 아치를 놓고, 숲을 만들고, 카메라 지역을 추가
  - `CameraFollow`: 여러 지역 지원
  - `LockedExit`: 그림 배치 함수 분리
  - `PlayerAction`: 묘목 자리 클릭 처리
  - `DataManager.EndDay`: 아침 숲 처리
  - `StoryEvents`: 일지(J)에 숲 진행 표시
  - `StoryState`: `forest` 추가

### Unity에서 확인할 것
- [ ] 마음이 30이 된 다음 아침에 아침 요약에 숲이 열렸다는 줄이 나오고, 서쪽 숲길에 꽃 아치가 보이는가
- [ ] 꽃 아치로 들어가면 숲 입구로 이동하고 카메라가 숲을 비추는가 (돌아올 때도)
- [ ] 숲의 나무, 개울, 큰 나무를 통과하지 못하는가 (`ForestWalls` 콜라이더)
- [ ] 회색 숲 위에서 되살린 빈터만 컬러로 보이는가
  - 안 보이면: 컬러 바닥의 Mask Interaction이 Visible Inside Mask인지, `ClearingColor`의 SpriteMask가 켜졌는지 확인

- [ ] 채집물이 보이고 걸어서 주울 수 있는가, 다음 날 새로 생기는가
- [ ] 곡괭이로 통나무를 치우면 남쪽 빈터로 갈 수 있는가
- [ ] 샘가 그루터기에서 E로 마음 +2, 물뿌리개 채우기가 되는가
- [ ] 숲에서 저장하고 불러와도 숲 상태(묘목, 큰 나무, 치운 통나무)가 유지되는가

## 맵 확장 4-1단계: 강가·호수 (10차 작업)

마음이 **여름(60)**이 된 다음 아침, 농장 남동쪽 길 끝의 회색 갈대가 초록으로 살아나 갈라지며 호수 길이 열립니다. 숲처럼 한 번 열리면 계속 열려 있습니다.

### 이번에 함께 바뀐 것
- **남쪽 길:** "Old Station"에서 노을 언덕(Sunset Hill)으로 바꿨습니다. 옛 기차역은 스타듀밸리와 비슷해서 계획에서 뺐습니다. 표지판 그림(해 지는 언덕)과 안내 문구도 바꿨습니다.
- **농장 맵:** 남동쪽에 호수로 가는 길을 내고, 호수 표지판을 세웠습니다.
- **출구 그림:** 맵 데이터의 출구에 `art`(잠김), `openArt`(열림) 그림을 적을 수 있게 했습니다. 숲은 가시덤불/꽃 아치, 호수는 회색 갈대/초록 갈대입니다.

### 호수 (`Assets/Resources/Maps/lake.json`, 30×20칸)
- 만드는 스크립트: `Tools/maps/make_lake_map.py`
- 글자: `# 나무  ~ 물  , 모래  . 풀  = 길  p 부두  R 갈대  F 낚시 자리  X 돌계단  h 벤치  W 버드나무  f 채집 자리  B 덤불`
- 서쪽 입구 → 서쪽 물가 돌계단 → 남쪽 물가 길 → 부두. 북쪽 물가에 버드나무와 벤치가 있습니다.
- Unity에서는 숲처럼 농장 씬 안 멀리(x 250~280)에 실행 중에 만듭니다.

### 호수 맑히기 (놓아주기)
- 호수는 회색으로 흐려져 있습니다.
- 서쪽 돌계단에서 E를 누르면, 가진 물고기를 놓아줄지 묻습니다(Y/N). 황금 잉어는 실수로 놓아주지 않게 뺍니다.
- 물고기마다 맑기 점수가 있습니다.

  | 물고기 | 점수 |
  |---|---|
  | 피라미 (Minnow) | 1 |
  | 잉어 (Carp), 블루길 (Bluegill) | 2 |
  | 문핀 (Moonfin) | 3 |
  | 유리고기 (Glassfish) | 4 |

- 맑기가 **10 / 25 / 45**를 넘을 때마다 서쪽 만 → 호수 가운데 → 동쪽 만 순서로 색이 돌아오고, 마음이 3 오릅니다.
- 다 맑아지면 마음이 5 더 오르고, 겨울이 아닌 밤(20시~새벽 4시)마다 호수 위에 반딧불이가 떠오릅니다.
- **구현:** 숲과 같습니다. 컬러 바닥(`bg_lake_<계절>`)을 회색 바닥 위에 마스크로 보여 줍니다. 구역별 마스크 위치는 `lake.json`의 `zones`에 있습니다.
- **선택:** 물고기를 팔면 돈이 되고, 놓아주면 호수가 되살아납니다. 플레이어가 고르는 구조입니다.

### 호수 낚시
- 부두 끝과 동쪽 물가에서 낚시할 수 있습니다.
- 낚을 수 있는 것:
  - 블루길 (35G)
  - 밤(19시 이후)에만 나오는 문핀 (110G)

- 규칙: `LakeState.LakeCatch`

## Unity에서 처음 열 때 (첫 실행 로그 확인 결과)

- **com.unity.2d.pixel-perfect 오류:** 처음 열 때 이 패키지에서 `PixelPerfectCamera`를 찾을 수 없다는 빨간 오류가 몇 줄 나옵니다.
  - Unity의 API Updater가 자동으로 고치고, 바로 다음 컴파일은 성공합니다.
  - 게임 코드(Assembly-CSharp)와는 관계없습니다.
- **빈 장면:** 새로 받은 프로젝트를 열면 Unity는 빈 장면(Untitled)을 띄웁니다. 여기서 ▶을 누르면 아무것도 나오지 않습니다.
  - `Assets/Editor/FarmPlayStart.cs`를 추가해서 해결했습니다. 이제 ▶을 누르면 항상 Farm 장면부터 시작하고, 빈 장면으로 열리면 Farm 장면을 자동으로 엽니다.
  - 게임 관리자가 Farm 장면에 있어서, 다른 장면에서 바로 시작하면 게임이 돌아가지 않기 때문입니다.
  - 끄려면 그 파일을 지우면 됩니다.
- **UI 크기:** 장면의 원래 UI는 1920×1080 기준 픽셀 위치인데 Canvas Scaler가 Constant Pixel Size여서, Game 창 크기가 다르면 막대·시간·핫바가 화면 밖으로 밀리고 글자가 크게 보였습니다.
  - `UIScale.cs`가 실행할 때 모든 장면의 Canvas Scaler를 Scale With Screen Size(1920×1080, 가로세로 0.5)로 바꿉니다.
  - Game 창은 16:9(예: Full HD 1920x1080)로 두는 것을 추천합니다.

## 픽셀 아트 화면 UI + 카메라 맞춤 (Unity 첫 실행 피드백)

### 픽셀 UI (`PixelHUD.cs`)
브라우저 미리보기와 같은 모양으로, 실행 중에 만듭니다. 장면 파일은 수정하지 않습니다.
- **왼쪽 위 정보 상자:** 계절(색), 날짜, 시간, 날씨, 골드, 마음
- **오른쪽 위 막대 상자:** HP, Food, Water, Energy. 에너지는 지금 마음에 따른 최대치 기준입니다.
- **아래 핫바 8칸:** 아이콘, 개수(물뿌리개는 남은 물), 숫자 키, 노란 선택 테두리, 위에 들고 있는 아이템 이름
  - `Hotbar.cs`가 이 칸들을 쓰고, 장면의 예전 핫바 그림은 숨깁니다.

  - 가방이 열려 있는 동안은 움직이거나 도구를 쓰지 않습니다. I 또는 Esc로 닫습니다.

- **그리는 순서:** 장면의 메뉴(상점, 제작, 상자)는 이 UI 위에 그려지고, 가방과 대화·알림은 맨 위입니다.

### 카메라 맞춤 (`CameraFit.cs`)

- 농장은 카메라가 따라가는 방식(CameraFollow)이라 그대로입니다.

- 입구와 출구는 **왼쪽 아래(서쪽)**입니다.
  - 남쪽 출구로 두면 농장 입구도 남쪽이라, 걸어 나오자마자 다시 들어가는 문제가 있었습니다.

### 과수원
- 늙은 과일나무 6그루가 있습니다. 사과 2, **배** 2, **감** 2입니다.
- 되살리는 순서: 회색 → 낫으로 **가지치기**(에너지 4) → **대지의 숨결** → 되살아남(마음 +2, 그 둘레에 색)
- 6그루를 모두 되살리면 마음이 5 더 오르고, 과수원 전체가 컬러가 됩니다.
- 되살아난 나무는 3일마다 열매 2개가 열립니다(겨울 제외). 클릭하면 땁니다.
- 스타듀밸리의 과일나무는 직접 심어 키우는 방식이고, 배와 감, 곶감은 없습니다.

## 출시 기본기 1: 효과음 + ESC 일시정지 메뉴 (12차 작업)

### 효과음 (`Sfx.cs`, `Assets/Resources/Audio/Sfx/`)
- 소리는 모두 `Tools/audio/make_sfx.py`로 합성해서 만듭니다. 라이선스 걱정이 없습니다. 고치려면 스크립트를 바꾸고 다시 실행합니다.
- 실행 중에 스스로 생기므로 장면에 넣을 것은 없습니다. 쓰는 법: `Sfx.Play("harvest")`

  | 소리 | 나는 때 |
  |---|---|
  | till / water / plant / harvest | 괭이질, 물주기, 심기, 수확이 실제로 됐을 때 |
  | hit / swish | 잔해 치기, 낫질 |
  | pickup / coin | 아이템을 얻을 때, 골드가 늘 때 |
  | heart | 마음이 1 이상 오를 때 |
  | step | 걸을 때 |
  | click / open / close | 버튼 누를 때, 일시정지 메뉴 열고 닫을 때 |

### ESC 일시정지 메뉴 (`PauseMenu.cs`)
- 계속하기 / 저장하기 / 볼륨(전체, 음악, 효과음) / 전체 화면 켜고 끄기 / 저장하고 끝내기
- 볼륨은 PlayerPrefs에 저장됩니다. 음악 볼륨은 장면의 반복 재생 AudioSource에 적용됩니다.
- 다른 창(가방, 대화, 앨범, 상점, 상자, 제작, 풍경)이 열려 있으면 ESC는 그 창만 닫습니다. 인트로와 게임 오버 중에는 열리지 않습니다.
- 열려 있는 동안 `Time.timeScale = 0`입니다.

### 프로젝트 설정
- 게임 이름(productName)을 "Survival Game"에서 **My Little Farmstead**로 바꿨습니다. 창 크기 조절도 켰습니다.
- 이름이 바뀌면 저장 폴더(`persistentDataPath`)도 바뀌어서, 예전 테스트 저장은 새 이름으로는 안 보입니다.
- 회사명(companyName)은 아직 DefaultCompany입니다. 출시 전에 스튜디오 이름으로 바꿔야 합니다.

### Unity에서 확인할 것
- [ ] 컴파일 에러가 없는가 (이번 작업은 Unity 없이 작성)
- [ ] ESC로 메뉴가 열리고 시간이 멈추는가, 가방/상점이 열린 상태에서 ESC는 그 창만 닫는가
- [ ] 볼륨 슬라이더가 바로 적용되고, 게임을 다시 켜도 유지되는가
- [ ] 괭이질/물주기/심기/수확/발소리가 들리는가

## 방향 C-1: 한국 시골 집과 텃밭 + 한국어/영어 (13차 작업)

스타듀밸리처럼 보이던 부분(덤불로 둘러싼 서양식 농장, 넓은 흙 아무 데나 괭이질, 잡초·그루터기·바위 개간, 밀짚모자 주인공)을 바꿨습니다.
시안: `Docs/concept/` (만드는 코드 `Tools/pixelart/kvillage.py`)

### 한국어 / 영어 (`Loc.cs`, `PixelFont.cs`, `ItemNames.cs`)
- 두 언어가 똑같이 기본입니다. 글은 코드 옆에 나란히 씁니다: `Loc.T("Harvested!", "수확했어요!")`
- 처음에는 컴퓨터 언어를 따르고(한국어면 한국어), ESC 메뉴의 **언어** 버튼으로 바꿉니다. 고른 언어는 PlayerPrefs(`lang`)에 저장됩니다.
- 글꼴: 영어는 Pixelify Sans, 한국어는 **갈무리 11** (`Assets/Resources/Fonts/Galmuri11.ttf`, SIL OFL 1.1, `Galmuri-OFL.txt`). 영어 글꼴에도 갈무리를 대체 글꼴로 붙여서 한글이 깨지지 않습니다.
- 아이템 ID는 영어 그대로(저장 파일, 레시피, 상점이 씀)이고, 화면에 보이는 이름만 `ItemNames.Display()`로 바꿉니다.
- **이번에 바꾼 글:** ESC 메뉴, 화면 위 정보(계절, 날짜, 날씨, 마음), 막대 이름, 가방, 핫바 아이템 이름, 밭일 안내(갈기, 물, 심기, 수확), 텃밭·퇴비 안내, 아침 요약의 텃밭 줄
- **아직 영어인 글:** 주민 대사, 편지, 일지, 앨범, 상점/제작 창, 대부분의 아침 요약과 안내. 주민은 C-2에서 한국 시골 사람으로 바뀌므로, 그다음에 한꺼번에 옮깁니다.

### 새 농장 지도 (`Assets/Resources/Maps/farm.json`, 만드는 스크립트 `Tools/maps/make_farm_map.py`)
- 크기와 좌표(36×20칸, x -9~27, y -15~5)와 출구 4곳(시장, 숲, 호수, 언덕)의 자리는 그대로입니다. 그래서 다른 지역과 도착 위치가 그대로 맞습니다.
- 뒷산 소나무(위), 개울과 징검다리(서쪽), 돌담 두른 마당과 집(왼쪽 위), 텃밭 4뙈기(오른쪽 위), 마을 길(가운데), 계단식 논(아래), 전봇대
- 글자: `. 풀  = 길  y 마당  s 징검다리  p 텃밭  S 벼 벤 논  * 꽃` (지나갈 수 있음) / `P 소나무  w 개울  W 돌담  H 집  J 장독대  K 감나무  B 평상  C 퇴비 더미  R 논  b 곤포  | 전봇대` (막힘) / `T 나무  r 돌  a 사과` (채집)
- **anchors:** 씬에 있던 물건을 실행 중에 옮겨 놓을 자리입니다. 집 문(HomePortal), 우물, 보관 상자, 퇴비 더미, 낚시 자리(개울), 미나, 별 덩굴, 새 게임 시작 자리, 엔딩 때 컬러 집 자리.
- 예전 한 화면 농장의 나무·돌·사과, 흙 타일, 장식 사각형(Square)은 실행 중에 치웁니다. **씬 파일은 고치지 않았습니다.**
- 벽 안이나 맵 밖에 서 있으면(새 게임, 예전 저장) 마당으로 옮깁니다.
- 그림: `Tools/pixelart/kfarm.py` (계절 4장). 겨울은 눈과 언 개울, 앙상한 감나무에 까치밥, 봄은 물 댄 논에 모, 여름은 푸른 벼, 가을은 누런 벼와 벼 벤 논의 곤포. 집은 엔딩 전까지 회색입니다(엔딩 A 그대로).

### 텃밭 뙈기 (`Plots.cs`, `FarmPlots.cs`)
- 넓은 흙 아무 데나 갈던 방식 대신, **정해진 텃밭 뙈기의 이랑**에서만 농사를 짓습니다. 한 칸이 이랑 한 줄의 한 자리입니다.
- 처음에는 앞 뙈기(6×3)만 열려 있고, 나머지 3뙈기는 **회색으로 굳은 묵정밭**입니다.
- **퇴비**로 되살립니다. 세 칸에 한 포대가 듭니다(작은 뙈기 4, 긴 뙈기 10, 구석 뙈기 2). 되살리면 마음 +2이고, 첫 작물부터 땅심 보너스를 받습니다.
- **땅도 쉬어야 한다 (휴경):** 작물 없이 하룻밤을 비워 둔 열린 뙈기는 "쉰 땅"이 됩니다. 빈 이랑에 짚이 덮이고, 그날 심는 작물은 **첫 수확 때 하나 더** 열립니다. 다시 자라는 작물(옥수수, 딸기)도 첫 수확에만 붙습니다.
- 스타듀밸리에는 정해진 뙈기, 휴경, 퇴비로 되살리는 땅이 없습니다.

### 퇴비 더미 (`CompostHeap`, 텃밭 왼쪽)
- 작물, 열매, 나물, 버섯, 도토리, 음식을 들고 E: 하나 넣기, Shift+E: 전부 넣기 (물고기, 씨앗, 도구, 정수, 나무, 돌은 안 됨)
- 두 개마다 다음 날 아침 퇴비 한 포대가 됩니다(쌓아 둘 수 있는 건 20포대까지). 다 되면 E로 꺼냅니다.
- 퇴비를 들고 묵정밭을 누르면 되살아납니다.

### 주인공
- 밀짚모자와 멜빵바지 대신 **짧은 머리, 오트밀색 카디건, 흰 티, 청바지, 흰 운동화**입니다(도시에서 내려온 사람). `Tools/pixelart/characters.py`

### 그 밖에
- 전망대 풍경의 "묵은 밭" 층은 이제 **묵정밭 3뙈기를 모두 되살렸을 때** 컬러가 됩니다.
- 흥정 장면은 그대로 위쪽(뒷산 길 끝 나무 문)으로 갑니다. C-2에서 장날로 옮길 예정입니다.
- 브라우저 미리보기도 새 농장(뙈기, 휴경, 퇴비, 벽, 새 자리)으로 바꿨습니다(영어만).

### 아직 남은 것 (다음 단계)
- C-2: 시장 → 시골 장터(오일장), 주민을 한국 시골 사람으로(이름, 그림, 대사), 빵 → 떡 같은 음식
- 우물(빨간 지붕)과 채집용 나무(서양 전나무) 그림을 한국 시골에 맞게
- 남은 글 한국어로 옮기기

### Unity에서 확인할 것
- [ ] 컴파일 에러가 없는가 (새 파일: `Loc.cs`, `ItemNames.cs`, `Plots.cs`, `FarmPlots.cs`, `HideArt.cs`, 글꼴 `Galmuri11.ttf`)
- [ ] 농장이 한국 시골 집으로 보이고, 집 문, 우물, 상자, 퇴비 더미가 마당과 텃밭 옆에 있는가
- [ ] 집, 돌담, 장독대, 개울, 논, 소나무를 통과하지 못하는가. 대문, 옆문, 뒷문으로는 나갈 수 있는가

## 방향 C-2: 시골 장터(오일장), 시골 사람들, 한국 음식, 모든 글 한국어/영어 (14차 작업)

### 오일장 (`MarketState.cs`, `MarketFair.cs`)
- 닷새마다 장날: `MarketState.IsMarketDay(day)` = 3일, 8일, 13일... (`day % 5 == 3`). `DaysUntilMarket`으로 아침 예보에 "내일은 장날" 이 뜹니다.
- 장날에 장터 씬에 들어가면 `WorldSpawner`가 `MarketFair`를 만듭니다: 노점 그림(`World/market_fair`, 뻥튀기 수레, 초록 천막, 옷 노점)을 배경 위에 깔고, 노점마다 부딪힘 상자, 초록 천막 앞에 흥정 할아버지(`World/haggler`).
- **흥정은 장날에만**, 할아버지 앞에서 E. 흥정 씬(MiniGame)이 끝나면 장터로 돌아옵니다(`HaggleGame.ReturnScene`). 농장 뒷산 길 위의 예전 흥정 문은 꺼 둡니다.
- 장날 상점에는 귀한 물건이 더 나옵니다(`FairStock`: 퇴비 30G, 대지의 숨결 180G, 햇살 조각 200G).

### 시골 사람들 (`VillagerDB.cs`, `Villager.cs`)
- 로사 → **복순 할머니**(방앗간, 떡), 테오 → **동수 아저씨**(철물점, 가게 뒤 대장간), 미나는 개울가 이웃집 아이. 저장 파일 호환을 위해 id(rosa, theo, mina)는 그대로입니다.
- 대사는 `L(영어, 한국어)` 쌍으로 적고, 언어를 바꾸면 목록을 다시 만듭니다.
- 그림: 복순 할머니(뽀글 파마, 자주색 조끼, 꽃무늬 몸빼), 동수 아저씨(남색 모자, 카키 작업 조끼), 장터 아주머니(챙 모자), 흥정 할아버지(밀짚모자). `Tools/pixelart/villagers.py`, `kmarket.py`.

### 한국 음식 (`ItemDB.cs`, `Craftingmanager.cs`)
- 빵 → **떡**, 옥수수 수프 → **찐 옥수수**, 당근 케이크 → **당근전**(당근 2 + 감자 1), 호박 파이 → **호박죽**(호박 1 + 떡 1).
- 예전 저장의 이름은 `ItemDB.Normalize`(별칭 표)로 새 이름이 됩니다. 앨범 "둘이 먹는 호박죽"도 새 이름으로.

### 장터 그림 (`Tools/pixelart/kmarket.py`)
- 뒷산 소나무, 흙길, 시멘트 마당, 간판(방앗간, 철물점, 행복슈퍼, 갈무리 글꼴), 파란 천막 가게, 쌀 포대, 평상과 플라스틱 의자, 빨간 고무 대야, 손수레, 스티로폼 화분, 전봇대. 사계절.
- 우물은 돌우물 + 두레박, 채집 나무는 소나무(적송)로 바꿨습니다.

### 모든 글 한국어/영어
- 토스트, 안내, 하루 요약, 편지, 엔딩, 일지, 앨범, 정령, 숲/저수지/언덕, 낚시, 개간, 흥정, 나눔 상자, 상점, 제작, 첫 안내까지 `Loc.T(영어, 한국어)`로.
- 아이템 설명: `ItemNames.Description(def)`(한국어 사전), 조사: `ItemNames.Josa / With`("당근을", "사과를").
- 잠긴 길 안내는 맵 데이터에 `signKo`를 더했습니다(`MapExit.Sign`). 영어로 "lake", 한국어로 "저수지".
- 개발용 키(F1~F6) 안내는 영어로 둡니다.

### 브라우저 미리보기
- 장날(노점, 귀한 물건, 흥정 할아버지), 새 음식 이름(예전 저장 이름 바꿈), 새 주민 대사(VillagerDB.cs에서 생성)를 넣었습니다. "장날로" 버튼. 게임 안 글은 여전히 영어만.

### Unity에서 확인할 것
- [ ] 컴파일 에러가 없는가 (새 파일: `MarketFair.cs`)
- [ ] 3일째(또는 F3로 하루씩 넘겨서) 장터에 가면 노점과 흥정 할아버지가 보이고 "오늘은 장날" 안내가 뜨는가
- [ ] 할아버지 앞 E → 흥정 → 끝나면 장터로 돌아오는가. 같은 날 다시 하면 "다음 장날에" 안내만 나오는가
- [ ] 장날이 아닌 날엔 노점이 없고, 농장 뒷산 길 위로 가도 흥정 씬으로 가지 않는가
- [ ] 장날 상점에 퇴비, 대지의 숨결, 햇살 조각이 보이는가
- [ ] 복순 할머니, 동수 아저씨 그림과 이름, 대사가 바뀌었는가. ESC에서 한국어로 바꾸면 대사도 한국어가 되는가
- [ ] 떡, 찐 옥수수, 당근전, 호박죽 아이콘과 레시피. 예전 저장의 빵이 떡으로 바뀌는가
- [ ] 한국어로 두고 한 바퀴 돌아보기: 영어가 남은 곳이 있으면 알려 주세요 (씬 파일 안에 직접 적힌 글은 아직 영어일 수 있어요)

## 방향 C-3: 뒷산, 저수지, 정자 (15차 작업)

## K-2: 장 담그기와 아궁이 (20차 작업)

콘텐츠 계획 둘째 단계 (B. 살림). 규칙은 `JangState.cs` (유니티 없이 테스트됨), 마당의 세 곳은 `JangSpots.cs`.

### 흐름
1. **아궁이** (집 왼쪽 벽에 붙은 부뚜막 + 가마솥): 장작(나무) 1개로 하루 한 번 불을 지핌 → 그날 밤 "뜨끈한 방바닥" (마음 +2, 일기 한 줄). 불을 지핀 뒤 다시 E (또는 그 앞에서 C) → 요리 창. 아궁이 앞에서는 모닥불 없이 요리 가능.
2. **메주 쑤기**: 아궁이에서 메주콩 4 + 나무 1 → 생메주 1 (요리 창의 새 조리법, 자리 "아궁이").
3. **메주 걸이** (저장 상자와 아궁이 사이): 생메주를 걸면 (한 번에 4개) 3일 뒤 마른 메주. E로 다 마른 것을 걷고 새로 건다. 겨울엔 짚 지붕에만 눈.
4. **장독대**: 빈 독(3개)에 마른 메주 1 + 소금 2. 재료가 되는 만큼 한 번에 채움 (그래야 다음 E는 언제나 뚜껑 열고 닫기).
5. **장독 돌보기**: 장독대에서 E = 뚜껑을 한꺼번에 열고 닫기. 밤마다, 뚜껑이 열려 있으면 맑은 날은 볕(care +1), 비·눈 온 날은 빗물(rain +1). 열린 동안엔 독 입구에 까만 장이 보이는 그림(`World/jangdok_open`).
6. **장 가르기**: 담근 지 8일 → 된장, 간장. 기본 된장 2·간장 1, 볕 3일↑ +1, 6일↑ +1, 빗물 2번↑ −1 (최소 1). 맛 한 마디가 바뀜 ("깊고 진하다. 볕이 다 들어 있다" / "순한 맛. 다음엔 볕을 더…"). 깜빡해도 망하지 않음.
- 처음 하는 일마다 한 번씩 방법 안내 (`howto_agungi`, `howto_meju`, `howto_jangdok`, `howto_jang`).

### 새 아이템, 조리법, 가게
- 메주콩(행복슈퍼 12G), 소금(8G), 생메주, 마른 메주(40G), 된장(60G), 간장(50G)
- 된장찌개 = 된장 + 감자 + 당근 (모닥불/아궁이), 감자조림 ×2 = 감자 2 + 간장
- 메주콩은 퇴비 더미에도 넣을 수 있음

### 방송, 일기
- 겨울인데 아직 장을 안 담갔으면 가끔: "겨울은 메주 쑤는 철입니다. 메주콩이랑 소금은 장터 행복슈퍼에…"
- 비·눈 오는 아침에 뚜껑이 열려 있으면: "장독 뚜껑 열어 둔 집은 얼른 가서 덮으시고요!"
- 일기: "아궁이에 불을 땠더니 밤새 방바닥이 뜨끈했다."

### 그림 (`Tools/pixelart/jang.py`)
- `World/agungi`, `agungi_fire` (아궁이에 불, 솥에서 김), `meju_rack`, `meju_rack_fresh`, `meju_rack_dried` (+ `_winter`), `jangdok_open` (장독대 그림과 같은 크기 78×52, 아래 가운데에 맞춤)
- 아이템: `soybeans`, `salt`, `fresh_meju`, `dried_meju`, `doenjang`, `ganjang`, `doenjang_stew` (뚝배기), `braised_potatoes`

## K-3: 품앗이, 새참, 마실과 이웃 네 명의 겨울 이야기 (21차 작업)

콘텐츠 계획 셋째 단계 (A. 정). "○○ 가져다줘" 심부름 소원 9개를 모두 없애고, 이웃마다 **이야기 3장**으로 바꿈.
한 장을 넘길 때마다 그 사람에게 색이 1/3씩 (예전과 같은 색 단계). 규칙은 `Neighbors.cs` (유니티 없이 테스트됨),
대사는 `VillagerDB.cs`의 `ChapterDef`, 장면과 보상은 `NeighborScenes.cs`.

### 세 가지 동사
- **품앗이**: 낮에 말을 걸면 부탁 → 그 사람 일터의 자리에서 [E] 세 번 (기력 3씩, 실패 없음). 끝나면 그 사람이 **내 일을 거들어 줌**.
- **새참**: 낮에 음식을 손에 들고 말을 걸면 같이 앉아 먹음. 이야기 장이면 장면, 아니면 짧은 한 마디 + 마음 (이웃마다 하루 한 번). 좋아하는 선물이나 호감도 숫자는 없음.
- **마실**: 저녁 6~10시에 이웃은 자기 자리(평상, 의자)에 나와 앉아 있음 → 말을 걸고 "앉기" → 주인공도 옆에 앉고, 이야기 한 자락, 한 시간이 흐름. 하룻저녁에 한 집. 이야기를 다 넘긴 뒤에도 매일 저녁 짧은 마실 가능.
- 장과 장 사이 이틀 (하루에 몰아서 못 함). 첫 장은 만난 날 바로.

## K-4: 동지와 정월대보름 (22차 작업)

콘텐츠 계획 넷째 단계 (C. 절기). 축제가 아니라 마을의 의식: 가게, 대회, 점수, 실패 없음.
**함께 준비 → 의식 → 나에게 하는 일**. 규칙은 `RiteState.cs` (`Rites`, 유니티 없이 테스트됨), 장면은 `RiteScenes.cs`, 고르기 창은 `ChoiceMenu.cs`.

### 동지 (7일째)
- 5일째 아침 방송 → 5~7일 낮, 장터 방앗간 앞 **팥죽 솥**에서 E 세 번 (팥 고르기, 팥 거르기, 새알심 빚기)

  → 마음 +6, 큰 색 물결, 일기 한 줄

- **소원지대로 산 날**: 봄부터 제때 자기 / 마실 / 밥 먹기 / 쉼터에서 쉬기 중 고른 것을 한 날은 마음 +1과 일기 "소원지에 쓴 대로, …"

## N-1: 밤 화면 (27차 작업)

예전에는 `LightingManager`가 2D 전역 조명 밝기만 낮췄는데, 그림 머티리얼에 따라 거의 안 보였고 미리보기에는 밤이 없었음. 이제 **화면 덮개 + 불빛 구멍** 방식으로 바꿈 (Unity와 미리보기가 같은 계산).

- **`NightCurve.cs`** (Unity 없이 계산만, 로직 테스트 있음): 시간대 색과 어둡기.
  - 17~19시 노을(주황) → 19~21시 푸른 저녁 → 21시~새벽 4시 밤 → 4~6시 새벽(푸르다 살짝 분홍)
  - 밤 어둡기 **중간** (`NightA` 0.58). 비·눈 오는 밤 ×1.12, 대보름 밤은 달빛으로 조금 밝고 푸르게 (×0.92)
  - 불빛 세기는 6단 띠로 끊음 (부드러운 번짐 대신 픽셀 그림처럼 동그란 띠)
- **`NightLight.cs`**: 카메라 앞에 화면만 한 덮개 그림 하나 (월드 그림 2픽셀 = 덮개 1칸, 맨 위 정렬 층 32000).
  - 덮개는 월드 그림이라 **HUD, 단축칸, 대화창, 메뉴는 안 어두워짐**. 2D 조명 설정이나 따로 할 일 없음.
  - 카메라를 따라가되 2픽셀 칸에 맞춰 놓아서 걸어도 불빛 띠가 안 떨림. 카메라가 움직인 뒤에 그림 (`DefaultExecutionOrder(1000)`).
  - 불빛 = `NightGlow` 컴포넌트. 불빛 자리는 어둠을 걷어내고 따뜻한 색을 얹음.
  - **농장**: 우리 집 창호지 (가운데 문 두 짝 + 양쪽 창 + 마당), 전봇대 보안등 (farm.json의 `|` 칸마다), **불 땐 날 아궁이** (일렁임)
  - **장터**: 방앗간 셔터, 철물점·행복슈퍼·마을회관 유리문 (+ 문 앞 바닥), 확성기 전봇대 보안등
  - **의식**: 달집 불 (크게 일렁임, 반지름 4.2칸), 쥐불 깡통 (돌아가는 불), 대보름 밤 달빛
  - 주인공 둘레 아주 약한 빛 (밤길이 아예 안 보이지 않게)
  - **방 안** (집, 방앗간, 행복슈퍼, 회관): 어둡게 하지 않고 백열등 같은 따뜻한 빛만 살짝 (밤일 때)
  - 별의 언덕, 타이틀, 오프닝에서는 꺼짐
- **그림**: 전봇대에 작은 **보안등** (왼쪽으로 굽은 팔, 갓, 전구)을 달아서 다시 뽑음 (`kvillage.pole(lamp=True)`). 농장·장터 배경, 오프닝, 타이틀 그림이 바뀜.
