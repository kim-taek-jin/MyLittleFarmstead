# 개발 노트 — 1차 개선 작업

Unity 에디터 없이 작업했습니다. 대신 이렇게 검증했습니다.
- **컴파일:** 스크립트 전체를 Unity 2021.3 참조 어셈블리와 UGUI/TMP/URP API 스텁으로 C# 9 컴파일. 에러와 경고 모두 0개.
- **로직 테스트:** 농장 성장, 시장 가격, 아이템/작물 연결을 콘솔에서 단위 테스트로 확인.

**실제 Unity에서 한 번 열어 아래 체크리스트를 확인해 주세요.**

## 조작법

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 1~5 / 마우스 휠 | 핫바 아이템 선택 (아이템이 5개보다 많으면 휠로 넘김) |
| 왼쪽 클릭 | 도구, 씨앗, 정수 사용 / 다 자란 작물 손으로 수확 |
| 오른쪽 클릭 / F | 들고 있는 음식 먹기 |
| E | 상호작용 (우물, 침대, 상점, 보관함) |
| C | 제작 창 |
| Esc | 열린 창 닫기 |
| F5 / F9 | 저장 / 마지막 저장 불러오기 |
| Ctrl+Shift+N | 저장을 지우고 새 게임 |

자동 저장: 잠들 때(또는 기절했을 때) 저장됩니다.

## 고친 버그

1. 딸기·옥수수·감자 씨앗을 사도 핫바에 안 보여서 심을 수 없던 문제 → 핫바가 `ItemDB` 분류로 표시
2. 무엇을 심든 당근이 수확되던 문제 → 작물마다 데이터(`CropDB`) 분리
3. 씬을 다녀오면 갈아둔 땅, 물 준 땅, 성장 상태가 초기화되던 문제 → 농장 데이터를 `DataManager.farm`에 보관
4. 작물이 실시간 15초마다 자라던 문제 → **물을 준 날 수** 기준 성장으로 변경
5. 보관함에서 아이템이 사라지거나 중복 키 예외가 나던 문제 → 클릭 1개, Shift+클릭 전부 이동
6. 씬 이동 후 핫바 선택이 어긋나던 문제(파괴된 Hotbar 참조) → `Hotbar.Instance` + 선택 기억
7. 핫바 순서가 인벤토리 변경 때마다 바뀌던 문제 → 도구 → 씨앗 → 음식 → 작물 → 정수 고정 순서
8. EventSystem이 없는 씬(Home)에서 클릭하면 NullReference가 나던 문제 → null 체크
9. 흥정 미니게임으로 골드를 무한히 벌던 문제 → 하루 1회, 시장 판매가 보너스로 변경
10. 도구를 1골드에 팔 수 있던 문제 → 도구는 판매 목록에서 제외
11. 게임 오버 후 RESTART를 누르면 체력 0 상태라 바로 다시 게임 오버되던 문제 → 마지막 저장(아침)에서 재시작
12. RESTART 버튼이 파괴된 DataManager를 가리키던 문제(농장으로 돌아온 뒤 버튼 무반응) → 런타임에 다시 연결
13. Farm을 다시 불러오면 생기는 중복 GameManager가 `ItemAssets.Instance`, 시간 매니저를 덮어쓰던 문제
14. 나무, 돌, 사과가 씬에 다시 들어갈 때마다 부활하던 문제 → 하루가 지나야 다시 자람
15. 시장 아이템 오타 `Potaoto Seed` → `Potato Seed` (예전 이름도 자동 변환)
16. 하루가 약 27초였던 문제 → `minutesPerSecond` 45 → 2 (06:00~02:00 하루 ≈ 10분)
17. 배고픔/갈증이 초 단위로 줄어 100초 만에 굶던 문제 → 게임 시간 기준(시간당 5 / 7)
18. 시작할 때 먹을 것이 없던 문제 → 사과 3개 지급, 시장에 빵·사과 추가
19. 침대 태그에 닿기만 해도 자던 중복 로직 제거 (E키로만)
20. 일부 스크립트의 한글 주석이 깨지던 인코딩(CP949) → UTF-8로 통일

## 새 기능

- **마음(Heart) 시스템 + 세상의 채도**: `DataManager.heart`, `WorldColor.cs` (기획서 Pillar 1, 2)
- **하루 평가 요약 화면**: 잠들 때 생활을 평가하고 마음 변화를 보여줌
- **날씨**: 비 오는 날은 밭 자동 물주기, 조명이 어두워짐
- **낮/밤 조명**: Global Light 2D 밝기를 시간대에 따라 조절
- **새벽 2시 기절**: 골드 10% 분실, 마음 −8, 집에서 깨어남
- **물뿌리개 용량**: 기본 10회 / 구리 25회. 우물(E)에서 충전
- **도구 업그레이드**: Fertile Hoe(3칸 갈기), Copper Watering Can(3칸 물주기, 제작 가능), Scythe(주변 3×3 수확)
- **자연의 정수 사용**: Sunshine Shard = 황금 작물(수확량 +1), Earth's Breath = 즉시 하루 성장
- **요리**: 모닥불(Campfire)을 가지고 있으면 Roasted Carrot / Baked Potato / Corn Soup / Strawberry Jam 제작
- **다시 열리는 작물**: Corn, Strawberry는 수확 후 3일마다 다시 열림
- **살아있는 시장**: 오늘의 수요 작물(+50%), 많이 팔면 가격 하락, 흥정 보너스
- **세이브/로드**: `Application.persistentDataPath/save.json`
- **화면 안내 UI(HUD)**: 상단 상태줄, 알림 메시지, 공지 패널. 코드로 자동 생성되므로 씬 작업이 필요 없음
- **임시 아이콘**: 스프라이트가 없는 아이템은 아이템 색 동그라미 아이콘을 자동 생성

## Unity에서 확인할 체크리스트

열기 전에 할 일: 예전에 플레이한 저장이 없으므로 그냥 Farm 씬에서 Play 하면 됩니다.

- [ ] 콘솔에 컴파일 에러가 없는가
- [ ] Farm 씬 Play → 인트로 → GameStart → 조작 안내 공지가 뜨는가
- [ ] **화면이 회색에 가까운가** (채도 −60%). 아니라면 아래 "채도가 안 바뀔 때" 참고
- [ ] 상단 가운데 상태줄(Heart / 날씨 / Water / Holding)이 보이는가
- [ ] 핫바에 Hoe, Watering Can, Scythe, Carrot Seed, Apple이 보이고 1~5와 휠로 선택되는가
- [ ] 괭이로 흙 갈기 → 씨앗 심기 → 물 주기 → 집(Home)에서 잠자기(18시 이후) → 다음 날 작물이 자랐는가
- [ ] 농장 → 시장 → 농장으로 왔을 때 갈아둔 땅과 작물이 그대로인가
- [ ] 우물에서 E → 갈증 회복, 물뿌리개 충전
- [ ] 시장에서 판매 탭: 도구가 안 보이고 가격이 `x개수 가격G`로 표시되는가
- [ ] 흥정 미니게임은 하루 1회만 되는가
- [ ] 게임을 껐다 켜면 마지막으로 잠든 아침 상태로 이어지는가

### 채도가 안 바뀔 때
`WorldColor.cs`는 카메라의 Post Processing을 코드로 켭니다. 그래도 안 보이면:
1. Main Camera → Rendering → **Post Processing** 체크 확인
2. `Assets/Settings/Renderer2D` 에 Post-processing 데이터가 연결되어 있는지 확인 (현재 연결되어 있음)

### 밸런스 조절 (인스펙터에서 바로 변경 가능)
- `GameManager > GameTimeManager > minutesPerSecond`: 하루 길이 (2 = 약 10분)
- `GameManager > DataManager > hungerPerGameHour / thirstPerGameHour`: 배고픔, 갈증 속도
- `GameManager > DataManager > startingHeart`: 시작 마음 (낮을수록 처음 화면이 회색)
- `Grid > CropManager`: 밭일 에너지 소모량
- 아이템 가격, 작물 성장 일수는 `ItemDB.cs`, `CropDB.cs`에서

### 알려진 한계 / 다음에 할 일
- 레시피가 늘어서 제작 창이 넘칠 수 있습니다. `recipeContentParent`에 ScrollRect를 달아 주세요.
- `SampleScene`은 빌드에서 꺼져 있고 수정하지 않았습니다.

## 픽셀 아트 (2차 작업)

모든 게임 그림을 **32×32 픽셀 기준의 통일된 스타일**로 새로 만들었습니다. 같은 팔레트, 자동 외곽선, 왼쪽 위 광원을 씁니다.
- 전체 목록: `Docs/pixelart_preview.png`
- 게임 화면 예시: `Docs/pixelart_scene_mock.png`

| 분류 | 개수 | 내용 |
|---|---|---|
| 아이템 아이콘 | 24 | 도구 5, 씨앗 봉투 4, 작물 4, 음식 7(사과, 빵, 요리 4종), 나무, 돌, 정수 2, 모닥불 |
| 작물 성장 단계 | 16 | 당근, 감자, 옥수수, 딸기 × 4단계 (씨앗 → 새싹 → 성장 → 수확) |
| 땅 타일 | 3 | 흙, 갈린 흙, 젖은 흙 (이어 붙여도 경계가 안 보이는 타일) |
| 월드 오브젝트 | 8 | 나무, 바위, 사과, 우물, 보관 상자, 침대, 출구 표지판, 상인 |
| 플레이어 | 9 | 아래, 위, 옆 × 걷기 3프레임 (왼쪽은 좌우 반전) |

### 어떻게 적용되나 (씬 파일 수정 없음)
- **아이콘:** `ItemAssets`가 `Resources/PixelArt/Items`에서 자동으로 찾습니다. 우선순위는 Extra Sprites → 픽셀 아트 → 예전 그림 → 임시 아이콘 순입니다.
- **작물:** `Crop`이 작물 ID별 성장 스프라이트를 불러와 밭 한 칸 크기에 맞춥니다.
- **타일:** `Assets/Tiles/*_Tile.asset`이 새 타일 스프라이트를 쓰도록 바꿨습니다. 예전의 갈색 사각형 GameObject는 더 이상 생성되지 않습니다.
- **월드 오브젝트:** `PixelArtWorld`가 씬이 열릴 때 원래 그림을 숨기고, 같은 위치와 크기에 픽셀 아트를 겹쳐 그립니다. 콜라이더와 스크립트는 그대로입니다.
- **플레이어:** `PlayerPixelAnimator`가 자동으로 붙어서, 이동 방향에 따라 걷기 애니메이션을 재생합니다.
- **예전 그림으로 되돌리기:** `GameManager > ItemAssets > Use Pixel Art` 체크 해제 (타일은 git으로 되돌리기)

### 그림 수정 / 추가하는 법
그림은 손으로 찍은 PNG가 아니라 **코드로 그립니다.** `Tools/pixelart/`의 파이썬 파일을 고친 뒤 실행하면 PNG와 Unity 설정(.meta)이 다시 만들어집니다.
GUID가 경로 기준으로 고정이라, 다시 만들어도 Unity 연결은 끊기지 않습니다.

```bash
pip install pillow
```

```bash
python3 Tools/pixelart/generate.py
```

```bash
python3 Tools/pixelart/mockup.py
```

| 파일 | 내용 |
|---|---|
| `pixel.py` | 팔레트, 도형, 명암, 자동 외곽선 도구 |
| `items.py` | 아이템 아이콘 |
| `crops.py` | 작물 성장 단계, 땅 타일 |
| `world.py` | 월드 오브젝트, 플레이어, 상인 |

- **새 아이템 아이콘:** `items.py`의 `ITEMS`에 `'아이템_이름': 함수`를 추가하면 됩니다. 키는 아이템 이름을 소문자로 바꾸고, 공백은 `_`로, 따옴표는 빼서 만듭니다. 예) `Earth's Breath` → `earths_breath`
- **새 작물:** `crops.py`의 `CROPS`에 4단계 함수를 추가하고, `CropDB.cs` / `ItemDB.cs`에 등록하면 됩니다.
- Aseprite 같은 툴로 직접 그린 그림으로 바꾸고 싶으면, 같은 이름의 PNG(32px)를 덮어쓰면 됩니다.

### Unity에서 확인할 것 (픽셀 아트)
- [ ] 핫바, 상점, 보관함, 제작 창 아이콘이 새 그림으로 보이는가
- [ ] 밭의 흙, 갈린 흙, 젖은 흙 타일이 새 그림인가 (갈색 사각형이 사라졌는가)
- [ ] 작물이 밭 한 칸 크기로 보이고, 단계별로 그림이 바뀌는가
- [ ] 나무, 바위, 사과, 우물, 상자, 침대, 출구, 상인이 새 그림으로 바뀌고 위치가 자연스러운가
- [ ] 플레이어가 걸을 때 방향별 애니메이션이 나오는가
- [ ] 크기가 어색하면: `PixelArt.Overlay`의 `fill`(기본 0.9) 값이나 오브젝트 Scale을 조절

### 배경 (3차 작업)
배경 5장(농장, 집, 시장, 흥정 미니게임, 회색 도시)도 픽셀 아트로 새로 그렸습니다. `Tools/pixelart/backgrounds.py`
- **같은 픽셀 밀도:** 배경도 32px = 1유닛이라, 캐릭터·작물·타일과 픽셀 크기가 같습니다. 크기가 섞이지 않는 것이 "AI 그림 같지 않게" 보이는 핵심입니다.
- **실제 배치 기준 구도:** 씬의 실제 좌표에 맞춰 그렸습니다. 밭 타일 영역, 집 포털(왼쪽 아래 → 오두막 문), 시장 포털(오른쪽 아래 → 표지판), 흥정 포털(위 → 나무 아치), 우물로 가는 길, 침대·출구 문·상인 노점 위치 등.
- **의도적인 배치:** 무작위 노이즈 대신 반복 타일(잔디 3종)과 손으로 정한 디테일(꽃 무리, 연못, 울타리, 우편함, 장작더미)을 씁니다. 광원은 모두 왼쪽 위입니다.
- **적용 방식:** `PixelArtWorld`가 예전 배경 위에 같은 크기로 정확히 겹쳐 그립니다. 나무는 1.45배로 키우고 밑동을 고정해서 플레이어보다 크게 보입니다.
- **미리보기:** `Docs/pixelart_bg_*.png`, 오브젝트를 배치한 농장 장면은 `Docs/pixelart_bg_farm_scene.png`
- **실제 오브젝트를 올려 보는 미리보기:** `python3 Tools/pixelart/scene_preview.py 출력.png`

### 흥정 장면 / 캐릭터 다시 그리기 (4차 작업)
- **상인 (`Tools/pixelart/haggle.py`):** 도형 명암을 빼고, 픽셀 지도에 한 점씩 직접 찍었습니다. 왼쪽 절반을 그린 뒤 좌우를 맞추고, 귀 뒤 연필이나 주머니 연필 같은 비대칭 디테일을 따로 넣었습니다.
- **명암:** 왼쪽 위 광원 기준으로 경계가 딱 끊기는 3단계 셀 셰이딩만 씁니다. 외곽선은 짙은 갈색 하나로 통일했습니다.
- **흥정 장면:** 절반 해상도로 그린 뒤 화면 전체를 2배로 키웠습니다. 클로즈업이라 픽셀이 더 크지만, 한 화면 안에서는 픽셀 크기가 같습니다.
- **소품:** 똑같은 것을 반복하지 않고 하나씩 다르게 배치했습니다. 자는 고양이, 마늘 다발, 달력, 칠판 가격표, 장부와 깃펜, 동전 더미, 저울, 종, 앞쪽의 과일 상자와 자루.
- **시장 상인:** 같은 디자인으로 작게 다시 그렸습니다.
- **플레이어 (`Tools/pixelart/characters.py`):** 9프레임 모두 같은 방식(픽셀 지도 + 같은 외곽선)으로 다시 그려서, 상인과 같은 게임 캐릭터처럼 보입니다.

## 회색 주민 시스템 + 새 콘텐츠 (5차 작업)

미리보기: `Docs/villagers_market_preview.png`, `Docs/villagers_stages.png`

### 회색 주민
마을 주민들도 주인공처럼 색을 잃었습니다. 소원을 하나 들어줄 때마다 색이 1/3씩 돌아오고, 3개를 모두 들어주면 완전히 컬러가 됩니다.

| 주민 | 위치 | 소원 1 | 소원 2 | 소원 3 |
|---|---|---|---|---|
| **Grandma Rosa** (빵집 할머니) | 시장 빵집 앞 | 당근 3 → 빵 3 + **당근 케이크 레시피** | 옥수수 2 + 사과 2 → 150G | 딸기잼 1 → 300G + 당근 케이크 2 |
| **Theo** (대장장이) | 시장 도구점 앞 | 나무 10 → **구리 물뿌리개 레시피** | 돌 15 → 200G + 비옥한 괭이 | 햇빛 조각 + 대지의 숨결 → 500G |
| **Mina** (아이) | 농장 연못가 | 사과 2 → **낚싯대 (낚시 해금)** | 잉어 1 → 딸기 씨앗 3 | 햇빛 조각 + 딸기 2 → 해바라기 씨앗 5 + **시장 판매 해금** |

- **처음 만날 때:** 사연과 첫 소원을 이야기합니다. 머리 위에 `!` 말풍선이 뜨면 할 이야기가 있거나 소원 아이템을 가지고 있다는 뜻입니다.
- **아이템 전달:** 다 모았으면 E로 대화하고 `[Y] Give`를 누르면 됩니다. 보상, 마음 상승, 색 회복 연출이 나옵니다.
- **정의 파일:** `VillagerDB.cs` (대사, 소원, 보상). 새 주민을 추가하려면 여기에 한 명 추가하고, `Tools/pixelart/villagers.py`에 그림을 추가하면 됩니다.
- **배치:** `WorldSpawner.cs`가 씬이 열릴 때 코드로 배치합니다. 씬 파일 수정이 필요 없습니다.

### 새 콘텐츠
- **낚시:** 농장 연못 근처에서 E → 기다렸다가 `!!`가 뜨면 바로 E. 미나에게 받은 낚싯대가 필요합니다.
  - Minnow 15G, Carp 45G, Golden Koi 300G (마음이 높을수록 잘 잡힘), 가끔 Old Boot
- **요리 추가:** 생선구이(작은 물고기 또는 잉어 + 나무), 당근 케이크(당근 2 + 빵). 둘 다 모닥불과 해금이 필요합니다.
- **해바라기:** 5일 성장, 90G. 수확할 때마다 마음 +2.
- **도시에서 온 편지:** 4일째와 10일째 아침에 옛 상사의 제안이 옵니다.
  - 수락하면 골드를 얻지만 마음이 크게 깎입니다 (400G / −12, 1500G / −25).
  - 거절하면 마음이 오릅니다. 10일째 편지를 찢으면 엔딩 문구가 달라집니다.
- **생활 일지 (J):** 마음, 골드, 주민별 진행도와 현재 소원, 잡은 물고기 도감.
- **엔딩:** 주민 3명 모두 색을 되찾고 마음이 90 이상이면 "Happiness, rebuilt" 엔딩이 나옵니다. 그 뒤에도 계속 플레이할 수 있습니다.
- **대화 UI:** 아래쪽 대화 상자에 초상화, 이름, 대사가 나옵니다. `[E]`로 넘기고 `[Y]`/`[N]`으로 선택합니다. HUD가 코드로 만듭니다.

### 바뀐 점
- 구리 물뿌리개 레시피는 이제 처음부터 보이지 않고, 테오의 첫 소원을 들어줘야 열립니다.

### Unity에서 확인할 것
- [ ] 시장에 회색 로사와 테오, 농장 연못가에 회색 미나가 서 있는가 (크기가 플레이어와 같은가)
- [ ] E로 대화 → 대화 상자 → 아이템을 모아서 다시 E → `[Y] Give` → 색이 1/3 돌아오는가
- [ ] 미나에게 낚싯대를 받고 연못에서 낚시가 되는가
- [ ] 4일째 아침 편지 선택지(Y/N)가 뜨는가
- [ ] J로 일지가 열리고 닫히는가
- [ ] 저장하고 다시 켜도 주민 진행도가 유지되는가

## 색을 먹는 정령 + 나눔 → 별의 언덕 (6차 작업)

시장놀이(조이월드)의 "새끼 용 키우기"와 "선행점수 → 하늘나라"를 이 게임의 주제에 맞게 바꿨습니다. 이름, 캐릭터, 그림은 가져오지 않았고 구조만 참고했습니다.
미리보기: `Docs/spirit_starhill_preview.png`

### 색을 먹는 정령
- **등장:** 처음으로 Sunshine Shard나 Earth's Breath를 얻으면 회색 아기 정령이 나타나 따라다닙니다.
- **먹이기 (G):** 들고 있는 아이템을 먹입니다. 4가지 색 기운이 쌓입니다.

| 색 | 먹이 | 능력 (어린 정령 / 다 큰 정령) |
|---|---|---|
| 햇빛 | Sunshine Shard +3, Sunflower +2, Corn +1 | 최대 에너지 +10% / +20% |
| 대지 | Earth's Breath +3, Carrot·Potato +1 | 물 준 작물이 밤사이 하루 더 자랄 확률 10% / 20% |
| 물 | Minnow +1, Carp·Grilled Fish +2, Golden Koi +5 | 황금 잉어 확률 +2% / +4%, 입질 시간 +0.2초 / +0.4초 |
| 꽃 | Apple·Strawberry +1, Strawberry Jam +3, Carrot Cake (대지 +1, 꽃 +2) | 매일 아침 마음 +1 / +2 |
| 전부 | **Star Fragment** (네 색 모두 +1) | 별의 언덕에서 주움 |

- **성장:** 경험치 8에서 어린 정령, 25에서 다 큰 정령이 됩니다. 가장 많이 먹은 색으로 모습이 정해집니다.
- **프리즘:** 다 큰 정령이 네 색을 고르게 먹으면(가장 적은 색이 가장 많은 색의 절반 이상) 희귀한 **프리즘** 정령이 되고, 모든 능력을 조금씩 받습니다.
- **도감:** 모습은 10가지입니다. 다른 색을 먹여 언제든 바꿀 수 있고, 만난 모습은 일지(J)에 기록됩니다. 새 모습을 만나면 마음 +2.
- **관련 파일:** `SpiritDB.cs` (먹이, 단계, 모습, 능력), `Spirit.cs` (따라다니기, 먹이기)

### 나눔 → 별의 언덕
- **나눔 상자:** 시장에 생겼습니다. 작물, 음식, 물고기를 들고 E로 1개, Shift+E로 필요한 만큼 나눕니다.
  - 나눔 점수는 개당 판매가의 1/10 (최소 1)이지만, **하루 최대 5점**까지만 받습니다. 비싼 것을 몰아 내도 하루 5점입니다.
  - 상한에 닿으면 그날은 아이템을 받지 않습니다 ("내일 또 와 주세요"). 점수 없이 아이템만 사라지지 않습니다.
  - 주민 소원을 들어주면 +3 (상한 없음). 하루 첫 나눔은 마음 +2.
- **별의 언덕:** 나눔 점수가 **60**이 되면 열립니다. 가장 빨라도 나눔 상자만으로 12일, 주민 소원 9개를 모두 들어줘도 7일이 걸립니다. 보통은 15~20일째쯤 열립니다. 맑은 밤(20시 이후, 비 안 옴)에 농장 오른쪽 위에 빛나는 덩굴이 자랍니다.
  - 덩굴 앞에서 E를 누르면 언덕으로 올라갑니다.
  - 밤마다 별 조각이 최대 10개 떨어지고, 걸어서 닿으면 줍습니다.
  - 벤치에서 E를 누르면 별을 봅니다. 밤마다 한 번 마음 +3.
  - 아래쪽 덩굴에서 E를 누르면 농장으로 내려갑니다.
- **구현 방식:** 언덕은 Farm 씬 안의 멀리 떨어진 곳(y +100)에 코드로 만들고, 올라가면 카메라를 옮겨서 보여줍니다. 새 씬 파일은 필요 없습니다.
- **관련 파일:** `DonationBox.cs`, `StarHill.cs`, `DataManager.AddKindness`

### Unity에서 확인할 것
- [ ] 정수를 처음 주우면 정령이 나타나 플레이어를 따라다니는가 (크기와 위치가 자연스러운가)
- [ ] G로 먹이면 색 기운이 오르고, 단계나 색이 바뀔 때 모습이 바뀌는가
- [ ] 시장 나눔 상자에서 E로 나누면 점수가 오르고, 하루 5점에서 멈추며, 60이 되면 안내가 뜨는가

## 마음의 계절 + 내일 예고 + 계절 앨범 + 데모 모드 (7차 작업)

미리보기: `Docs/heart_seasons_preview.png`

### 마음의 계절
달력이 아니라 **마음(Heart)이 계절을 정합니다.** 게임은 겨울(번아웃)에서 시작합니다.

| 마음 | 계절 | 새로 자라는 작물 |
|---|---|---|
| 0~29 | 겨울 | 당근, 감자 |
| 30~59 | 봄 | 딸기 |
| 60~84 | 여름 | 옥수수, 해바라기 |
| 85~ | 가을 | **호박** (새 작물, 호박 파이 레시피 해금) |

- **바뀌는 때:** 아침(잠에서 깬 직후)에만 바뀝니다. 계절이 오면 큰 안내 화면이 뜹니다.
- **꽃샘추위:** 다시 무리해서 그 계절 기준보다 마음이 5 넘게 떨어지면 한 계절 돌아갑니다.
- **작물:** 계절이 돌아가도 **시들지 않습니다.** 그 계절에 안 맞는 작물은 성장만 멈추고, 계절이 돌아오면 다시 자랍니다.
- **심기와 시장:** 지금 계절에 안 맞는 씨앗은 심을 수 없고, 시장에서도 팔지 않습니다. 오늘의 수요 작물도 제철 작물 중에서 고릅니다.
- **날씨:** 마음을 따라갑니다. 전날 마음이 +6 이상이면 비 확률이 절반, 전날 마음이 줄었으면 +30%입니다.
  - 겨울에는 비 대신 **눈**이 옵니다. 눈은 밭을 적시지 않습니다.
- **그림:** 농장과 시장 배경이 계절마다 바뀝니다.
  - 겨울: 눈 덮인 땅, 언 연못, 눈사람, 지붕 위의 눈
  - 봄: 꽃이 핀 덤불
  - 여름: 진한 녹음
  - 가을: 단풍, 낙엽, 호박
  - 나무, 바위, 우물, 상자, 표지판도 겨울엔 눈이 쌓이고, 나무는 가을에 노랗게 물듭니다.
- **비·눈 효과:** 야외(농장, 시장)에서 화면에 비와 눈이 내립니다 (`WeatherFX.cs`).
- **주민 대사:** 계절마다 다른 한마디가 있습니다.
- **관련 파일:** `SeasonSystem.cs` (기준값, 날씨 확률)

### 내일 예고
아침 요약 화면 맨 아래에 **"Today"** 줄이 붙습니다 (최대 3개). 예를 들면:
- 다 익은 작물 수
- "물을 주면 내일 익을 작물 N개"
- "봄까지 마음 N"
- "○○의 소원 아이템을 다 가지고 있어요"
- "오늘 밤 맑음: 별 덩굴이 자랍니다"
- "앨범에 남은 사진 N장"

### 계절 앨범 (P)
- 계절마다 사진 6장, 총 24장입니다. 조건을 달성하면 회색 실루엣이 컬러 사진으로 바뀝니다.
  - 예: 첫 당근 수확, 처음 낚은 물고기, 별의 언덕 방문, 황금 잉어
- **찍을 수 있는 때:** 그 계절이 왔거나 이미 지나간 뒤에만 찍을 수 있습니다. 지나간 계절의 사진도 나중에 찍을 수 있습니다 (놓쳐서 아쉬운 일 없음).
- **보는 법:** 못 찍은 사진엔 힌트가 보입니다. 아직 오지 않은 계절의 페이지는 "???"로 보입니다.
- **보상:** 한 계절 페이지를 다 채우면 300G와 마음 +5. 24장을 모두 모으면 특별 메시지가 나옵니다.
- **조작:** ←/→ 로 계절 페이지를 넘기고, P 또는 Esc로 닫습니다. 앨범을 여는 동안 플레이어는 움직이지 않습니다.
- **관련 파일:** `AlbumDB.cs` (사진 목록, `Album.Report`)

### 데모 모드
- **켜는 법:** `GameManager > DataManager > Demo Mode` 체크, 또는 Player Settings의 Scripting Define Symbols에 `DEMO_BUILD`를 추가합니다.
- **동작:** 마음이 봄 기준(30)에 닿는 아침에 "봄이 오고 있어요... 데모를 플레이해 주셔서 감사합니다" 화면이 뜹니다. 그 화면에서 Enter를 누르면 `Wishlist Url`(Steam 페이지)이 열립니다.
- **데모 종료 뒤:** 계절은 겨울에 머물고, 계속 플레이는 할 수 있습니다.

### Unity에서 확인할 것
- [ ] 새 게임이 겨울(눈 덮인 농장)로 시작하는가
- [ ] 마음이 30이 된 다음 아침에 "Spring has come" 화면과 함께 배경이 봄으로 바뀌는가
- [ ] 겨울에 딸기 씨앗을 심으면 안내가 뜨고, 시장에서 제철 씨앗만 파는가
- [ ] 비 또는 눈이 내리는 날 화면에 비·눈이 보이는가
- [ ] 아침 요약에 Today 줄이 나오는가
- [ ] P로 앨범이 열리고, 사진을 찍으면 알림과 함께 컬러로 바뀌는가
- [ ] Demo Mode를 켜면 봄 직전에 데모 종료 화면이 뜨는가
- [ ] 예전 저장 파일을 불러와도 문제가 없는가 (계절은 다음 아침에 마음에 맞게 정해짐)

## 브라우저 미리보기 (`Tools/webpreview/`)

Unity 없이 게임을 볼 수 있게, 같은 픽셀 아트와 규칙을 자바스크립트로 옮긴 웹 미리보기입니다. Unity 게임과는 별도로 만든 것이라 세부 동작은 조금 다를 수 있습니다.

- **구성:**
  - `game.js`: 게임 규칙 (아이템, 작물, 주민, 정령, 마음의 계절, 앨범, 낚시, 나눔, 별의 언덕, 흥정, 편지)
  - `template.html`: 화면, 조작 안내, 미리보기 도구 버튼
  - `build.py`: `Assets/Resources/PixelArt`의 그림을 전부 한 HTML 파일에 넣어 줍니다
- **다시 만들기:** `python3 Tools/webpreview/build.py 출력.html`
- **미리보기 도구:** 마음 +10, 하루 넘기기, 아이템 받기, 별의 언덕 열기, 밤으로, 4배속, 새로 시작. 계절 변화를 빨리 확인할 수 있습니다.

### 크기 / 밭 수정 (미리보기 피드백 반영)
- **크기:** 캐릭터, 주민, 정령, 나무, 바위, 우물, 상자, 침대, 상인을 모두 **배경과 같은 픽셀 크기(32px = 1유닛)**로 그립니다. 예전에는 원래 그림 크기에 맞춰 거의 2배로 그렸습니다. 이제 캐릭터 키는 밭 한 칸 정도입니다.
  - 구현: `PixelArt.Overlay(..., native: true)`, `PixelArt.CharacterScale = 1`
- **밭 테두리:** 밭 둘레에 흙 테두리를 배경에 그렸습니다. 겨울엔 눈이 쌓입니다.
- **갈린 흙 타일:** 칸마다 둥근 이랑(흙 둔덕)으로 다시 그려서 칸이 하나씩 구분됩니다.
- **맨흙 타일:** 점박이를 줄였습니다.
- **바닥 사과:** 작은 16px 사과 그림을 새로 그렸습니다.
- **Unity에서 확인할 것:** 콜라이더와 트리거(우물, 침대 등)는 예전 큰 그림 기준 크기라서, 그림보다 범위가 넓게 느껴질 수 있습니다. 어색하면 알려주세요.

## 맵 확장 1·2단계: 맵 기반 + 넓어진 농장과 개간 (8차 작업)

농장이 **화면 4장 크기(36×20칸)**로 넓어졌습니다. 예전 농장은 북서쪽에 같은 좌표 그대로 있어서 밭, 집, 우물, 연못, 흥정 문이 모두 그대로 동작합니다.

### 맵 데이터
- **파일:** `Assets/Resources/Maps/farm.json`
  - 만드는 스크립트: `Tools/maps/make_farm_map.py`
  - 한 글자가 한 칸(1유닛 = 32px)입니다. `. 잔디  = 길  x 빈 흙  g 잡초  k 그루터기  o 바위  T 나무  r 돌  a 사과  * 꽃  ~ 예전 농장`
  - 출구(`exits`)는 월드 좌표 사각형입니다. `locked`에는 그 길을 여는 마음의 계절을 적습니다.
  - `arrivals`는 다른 씬에서 농장으로 올 때 도착하는 위치입니다.
- **그림:**
  - `Tools/pixelart/farmmap.py`가 같은 파일을 읽어 `bg_farmmap_<계절>` 4장(1152×640)을 그립니다.
  - 예전 농장 그림 코드(`backgrounds.farm`)를 그대로 재사용하고, 길과 울타리 덤불만 늘렸습니다.
  - 미리보기: `Docs/pixelart_bg_farmmap_*.png`
- **맵을 고치려면:** `make_farm_map.py` 수정 → `python3 Tools/maps/make_farm_map.py` → `python3 Tools/pixelart/generate.py`

### 넓어진 농장 구성
- **큰 길:** 동쪽으로 이어지고, 길 끝(x 26.3~27)이 시장 출구입니다. 예전 시장 포털은 실행 중에 길 끝으로 옮겨집니다.
- **묵은 밭 (남동쪽 18×7칸):** 잡초 65, 그루터기 15, 바위 10개가 있습니다. 모퉁이 6칸은 처음부터 비어 있어 바로 갈 수 있습니다.
- **동쪽 초원, 남서쪽 들판:** 새 나무, 돌, 사과가 있습니다. 씬의 자원 프리팹을 복제한 것이라 채집 규칙과 다음 날 다시 자라는 규칙이 같습니다.
- **잠긴 길 두 곳:** 회색 가시덤불이 막고 있고, 부딪히면 표지판 말이 나옵니다.
  - 서쪽 숲길: 봄에 열림 (3단계)
  - 남쪽 옛 철길: 가을에 열림 (4단계)
  - 길 너머 지역은 아직 만들지 않았습니다. 지금은 계절이 와도 "곧 열린다"는 말만 나옵니다.

### 개간
| 대상 | 도구 | 횟수 (좋은 괭이) | 한 번에 에너지 | 얻는 것 |
|---|---|---|---|---|
| 잡초 | 낫 또는 괭이 | 1 | 2 | 없음 |
| 그루터기 | 괭이 | 3 (2) | 4 | 나무 2 |
| 바위 | 괭이 | 4 (3) | 4 | 돌 2, 가끔 대지의 숨결 |

- 전부 치우는 데 에너지 약 470이 들어서, 농사와 함께 하면 며칠이 걸립니다.
- 치운 칸은 바로 갈 수 있는 흙이 되고, `FarmData.clearedDebris`에 저장되어 다시 생기지 않습니다.
- 25%마다 진행도를 알려 주고, 다 치우면 마음 +5입니다.
- 그루터기와 바위는 지나갈 수 없고, 잡초는 밟고 지나갈 수 있습니다.

### 카메라
- 농장에서는 카메라가 플레이어를 따라가고, 맵 밖은 보이지 않습니다.
- 플레이어는 맵 밖으로 나갈 수 없습니다.
- 카메라는 픽셀 격자(1/32유닛)에 맞춰 움직여서 그림이 떨리지 않습니다.
- 별의 언덕에 올라가 있는 동안에는 따라가기를 멈춥니다.

### 새 스크립트 / 바뀐 스크립트
- **새 스크립트:**
  - `MapData.cs`: 맵 JSON 읽기
  - `FarmMap.cs`: 농장 씬이 열릴 때 바닥 그림, 흙 타일, 개간 대상, 자원, 출구, 카메라, 도착 위치를 설정
  - `Debris.cs`: 잡초, 그루터기, 바위
  - `CameraFollow.cs`: 플레이어 따라가기와 맵 경계
  - `LockedExit.cs`: 가시덤불로 막힌 길
- **바뀐 스크립트:**
  - `PixelArtWorld`: 맵이 있으면 `BackGroundFarm`을 큰 그림으로 교체. 복제한 자원용 `ApplyTo` 추가
  - `PlayerAction`: 클릭한 칸에 개간 대상이 있으면 먼저 처리
  - `FarmData`: `clearedDebris` 추가
  - `DataManager`: `IsResourceCleared` 추가
  - `HaggleGame`: 흥정이 끝나면 북쪽 문 앞으로 돌아옴
- **씬 파일은 고치지 않았습니다.** `farm.json`을 지우면 예전 한 화면 농장으로 돌아갑니다.

### Unity에서 확인할 것
- [ ] 농장에서 카메라가 플레이어를 따라가고, 맵 가장자리에서 멈추는가
- [ ] 큰 농장 그림 위에 밭 타일이 보이는가 (밭이 그림 아래로 숨으면 `FarmMap.PlaceGround`의 sortingOrder -50을 확인)
- [ ] 묵은 밭에서 잡초를 낫으로, 그루터기·바위를 괭이로 치우면 흙이 되고 갈 수 있는가
- [ ] 동쪽 길 끝에서 시장으로 가고, 시장에서 돌아오면 길 끝에 도착하는가
- [ ] 집, 흥정 장면에서 돌아올 때 위치가 자연스러운가
- [ ] 서쪽 숲길과 남쪽 철길의 가시덤불에 막히고 말이 나오는가
- [ ] 새 나무·돌·사과를 채집할 수 있고, 다음 날 다시 생기는가
- [ ] 별의 언덕에 올라갔다 내려와도 카메라가 정상인가
- [ ] 저장 후 다시 불러와도 치운 칸이 유지되는가
