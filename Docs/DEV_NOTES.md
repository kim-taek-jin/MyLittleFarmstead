# 개발 노트 — 1차 개선 작업

Unity 에디터 없이 작업했습니다. 대신 이렇게 검증했습니다.
- **컴파일:** 스크립트 전체를 Unity 2021.3 참조 어셈블리와 UGUI/TMP/URP API 스텁으로 C# 9 컴파일. 에러와 경고 모두 0개.
- **로직 테스트:** 농장 성장, 시장 가격, 아이템/작물 연결을 콘솔에서 단위 테스트로 확인.

**실제 Unity에서 한 번 열어 아래 체크리스트를 확인해 주세요.**

---

## 조작법

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 1~5 / 마우스 휠 | 핫바 아이템 선택 (아이템이 5개보다 많으면 휠로 넘김) |
| 왼쪽 클릭 | 도구, 씨앗, 정수 사용 / 다 자란 작물 손으로 수확 |
| 오른쪽 클릭 / F | 들고 있는 음식 먹기 |
| E | 상호작용 (우물, 침대, 상점, 보관함) |
| C | 제작 창 |
| Esc | 열린 창 닫기 |
| F5 / F9 | 저장 / 마지막 저장 불러오기 |
| Ctrl+Shift+N | 저장을 지우고 새 게임 |

자동 저장: 잠들 때(또는 기절했을 때) 저장됩니다.

## 고친 버그

1. 딸기·옥수수·감자 씨앗을 사도 핫바에 안 보여서 심을 수 없던 문제 → 핫바가 `ItemDB` 분류로 표시
2. 무엇을 심든 당근이 수확되던 문제 → 작물마다 데이터(`CropDB`) 분리
3. 씬을 다녀오면 갈아둔 땅, 물 준 땅, 성장 상태가 초기화되던 문제 → 농장 데이터를 `DataManager.farm`에 보관
4. 작물이 실시간 15초마다 자라던 문제 → **물을 준 날 수** 기준 성장으로 변경
5. 보관함에서 아이템이 사라지거나 중복 키 예외가 나던 문제 → 클릭 1개, Shift+클릭 전부 이동
6. 씬 이동 후 핫바 선택이 어긋나던 문제(파괴된 Hotbar 참조) → `Hotbar.Instance` + 선택 기억
7. 핫바 순서가 인벤토리 변경 때마다 바뀌던 문제 → 도구 → 씨앗 → 음식 → 작물 → 정수 고정 순서
8. EventSystem이 없는 씬(Home)에서 클릭하면 NullReference가 나던 문제 → null 체크
9. 흥정 미니게임으로 골드를 무한히 벌던 문제 → 하루 1회, 시장 판매가 보너스로 변경
10. 도구를 1골드에 팔 수 있던 문제 → 도구는 판매 목록에서 제외
11. 게임 오버 후 RESTART를 누르면 체력 0 상태라 바로 다시 게임 오버되던 문제 → 마지막 저장(아침)에서 재시작
12. RESTART 버튼이 파괴된 DataManager를 가리키던 문제(농장으로 돌아온 뒤 버튼 무반응) → 런타임에 다시 연결
13. Farm을 다시 불러오면 생기는 중복 GameManager가 `ItemAssets.Instance`, 시간 매니저를 덮어쓰던 문제
14. 나무, 돌, 사과가 씬에 다시 들어갈 때마다 부활하던 문제 → 하루가 지나야 다시 자람
15. 시장 아이템 오타 `Potaoto Seed` → `Potato Seed` (예전 이름도 자동 변환)
16. 하루가 약 27초였던 문제 → `minutesPerSecond` 45 → 2 (06:00~02:00 하루 ≈ 10분)
17. 배고픔/갈증이 초 단위로 줄어 100초 만에 굶던 문제 → 게임 시간 기준(시간당 5 / 7)
18. 시작할 때 먹을 것이 없던 문제 → 사과 3개 지급, 시장에 빵·사과 추가
19. 침대 태그에 닿기만 해도 자던 중복 로직 제거 (E키로만)
20. 일부 스크립트의 한글 주석이 깨지던 인코딩(CP949) → UTF-8로 통일

## 새 기능

- **마음(Heart) 시스템 + 세상의 채도**: `DataManager.heart`, `WorldColor.cs` (기획서 Pillar 1, 2)
- **하루 평가 요약 화면**: 잠들 때 생활을 평가하고 마음 변화를 보여줌
- **날씨**: 비 오는 날은 밭 자동 물주기, 조명이 어두워짐
- **낮/밤 조명**: Global Light 2D 밝기를 시간대에 따라 조절
- **새벽 2시 기절**: 골드 10% 분실, 마음 −8, 집에서 깨어남
- **물뿌리개 용량**: 기본 10회 / 구리 25회. 우물(E)에서 충전
- **도구 업그레이드**: Fertile Hoe(3칸 갈기), Copper Watering Can(3칸 물주기, 제작 가능), Scythe(주변 3×3 수확)
- **자연의 정수 사용**: Sunshine Shard = 황금 작물(수확량 +1), Earth's Breath = 즉시 하루 성장
- **요리**: 모닥불(Campfire)을 가지고 있으면 Roasted Carrot / Baked Potato / Corn Soup / Strawberry Jam 제작
- **다시 열리는 작물**: Corn, Strawberry는 수확 후 3일마다 다시 열림
- **살아있는 시장**: 오늘의 수요 작물(+50%), 많이 팔면 가격 하락, 흥정 보너스
- **세이브/로드**: `Application.persistentDataPath/save.json`
- **화면 안내 UI(HUD)**: 상단 상태줄, 알림 메시지, 공지 패널. 코드로 자동 생성되므로 씬 작업이 필요 없음
- **임시 아이콘**: 스프라이트가 없는 아이템은 아이템 색 동그라미 아이콘을 자동 생성

## Unity에서 확인할 체크리스트

열기 전에 할 일: 예전에 플레이한 저장이 없으므로 그냥 Farm 씬에서 Play 하면 됩니다.

- [ ] 콘솔에 컴파일 에러가 없는가
- [ ] Farm 씬 Play → 인트로 → GameStart → 조작 안내 공지가 뜨는가
- [ ] **화면이 회색에 가까운가** (채도 −60%). 아니라면 아래 "채도가 안 바뀔 때" 참고
- [ ] 상단 가운데 상태줄(Heart / 날씨 / Water / Holding)이 보이는가
- [ ] 핫바에 Hoe, Watering Can, Scythe, Carrot Seed, Apple이 보이고 1~5와 휠로 선택되는가
- [ ] 괭이로 흙 갈기 → 씨앗 심기 → 물 주기 → 집(Home)에서 잠자기(18시 이후) → 다음 날 작물이 자랐는가
- [ ] 농장 → 시장 → 농장으로 왔을 때 갈아둔 땅과 작물이 그대로인가
- [ ] 우물에서 E → 갈증 회복, 물뿌리개 충전
- [ ] 시장에서 판매 탭: 도구가 안 보이고 가격이 `x개수 가격G`로 표시되는가
- [ ] 흥정 미니게임은 하루 1회만 되는가
- [ ] 게임을 껐다 켜면 마지막으로 잠든 아침 상태로 이어지는가

### 채도가 안 바뀔 때
`WorldColor.cs`는 카메라의 Post Processing을 코드로 켭니다. 그래도 안 보이면:
1. Main Camera → Rendering → **Post Processing** 체크 확인
2. `Assets/Settings/Renderer2D` 에 Post-processing 데이터가 연결되어 있는지 확인 (현재 연결되어 있음)

### 밸런스 조절 (인스펙터에서 바로 변경 가능)
- `GameManager > GameTimeManager > minutesPerSecond`: 하루 길이 (2 = 약 10분)
- `GameManager > DataManager > hungerPerGameHour / thirstPerGameHour`: 배고픔, 갈증 속도
- `GameManager > DataManager > startingHeart`: 시작 마음 (낮을수록 처음 화면이 회색)
- `Grid > CropManager`: 밭일 에너지 소모량
- 아이템 가격, 작물 성장 일수는 `ItemDB.cs`, `CropDB.cs`에서

### 알려진 한계 / 다음에 할 일
- 감자, 옥수수, 딸기는 아직 전용 성장 스프라이트가 없어서 당근 스프라이트에 색만 입혀 구분합니다. `Crop` 프리팹을 작물별로 만들면 개선됩니다.
- 새 아이템(빵, 요리 등)은 임시 동그라미 아이콘입니다. `GameManager > ItemAssets > Extra Sprites`에 이름과 스프라이트를 추가하면 바로 바뀝니다.
- 레시피가 늘어서 제작 창이 넘칠 수 있습니다. `recipeContentParent`에 ScrollRect를 달아 주세요.
- `SampleScene`은 빌드에서 꺼져 있고 수정하지 않았습니다.
