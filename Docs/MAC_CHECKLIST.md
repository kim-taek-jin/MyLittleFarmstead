# 맥 겨울 점검표 (F-0)

그동안 각 작업마다 따로 적어 둔 "맥에서 확인할 것"을 **한 판 순서대로** 모은 표입니다.
처음부터 대보름 다음 날 봄 아침까지 한 번 해 보면서, 이상한 곳의 **번호**와 **무슨 일이 있었는지**(가능하면 스크린샷)를 알려 주세요.

## 준비

1. `git pull` → Unity 열기 → 가져오기(Import)가 끝날 때까지 기다리기
2. **Console 창을 열어 두기**: 빨간 오류가 나오면 그 줄을 복사해서 보내 주세요 (노란 경고도 있으면 같이)
3. `GameManager` 오브젝트의 `Demo Mode`
   - **꺼 두면**: 정식판 흐름. 대보름 다음 날 봄이 오고 계속 이어짐 (이번 점검은 이쪽 추천)
   - **켜 두면**: 데모 흐름. 대보름 다음 날 "데모 끝" 네 장
4. 개발 키 (에디터에서만): F1 다음 계절로 · F2 마음 +10 · F3 하루 넘기기 · F4 아이템 · F6 순간이동 · F7 엔딩 준비 · F8 목록 · F9 대보름 밤 바로
5. 예전 저장이 있으면 그대로 이어서 해도 됩니다 (새 계절 흐름에 맞게 옮겨짐). 깨끗하게 보려면 타이틀에서 "새로 시작".

## A. 시작 (1일째)

- [ ] A1 타이틀에 가야금 음악, 언어 바꾸기, 새로 시작 → 오프닝 → 농장
- [ ] A2 첫날 안내 3단계 카드가 겹치지 않는지
- [ ] A3 텃밭 갈기: 클릭한 칸이 정확히 갈리고 이랑과 줄이 맞는지, 괭이질 소리
- [ ] A4 눈 위를 걸을 때 "뽀득" 발소리, 하루가 실제 약 6분인지
- [ ] A5 세상이 거의 회색으로 시작하는지

## B. 집과 아궁이

- [ ] B1 집 문 → 미닫이 소리 → 온돌방 (가구 크기가 사람과 맞는지, 벽에 막히는지, 카메라가 방에 맞는지)
- [ ] B2 요에서 E로 자기 → 다음 아침 "어제의 일기" (숫자 없이), 일기장 넘기는 소리
- [ ] B3 아래 미닫이문으로 나가면 마루 앞
- [ ] B4 나무를 들고 아궁이 E → 불 붙는 소리와 불 그림 → 다시 E 또는 C → 생메주 / 집 보리차
- [ ] B5 메주 걸이 → (2일) 마른 메주 → 장독대 → 뚜껑 열고 닫기 (옹기 소리) → (4일) 된장·간장

## C. 장터와 가게 안

- [ ] C1 장터 음악, 아침 방송 "딩동댕동" 차임 + 이장님 방송 줄
- [ ] C2 방앗간·행복슈퍼·마을회관 문 앞 [E] → 안으로 (가게는 종소리, 나머지는 미닫이), 오른쪽 아래 문으로 나오면 그 가게 앞
- [ ] C3 방앗간 안 복순 할머니, 떡 시루 품앗이 (E 세 번)
- [ ] C4 행복슈퍼 안 아주머니에게 사고팔기: 메주콩, 소금, **병 보리차, 볶은 보리**
- [ ] C5 마을회관 왼쪽 옆 **수돗가** (겨울엔 천 감긴 수도꼭지): E → 물소리 + 꿀꺽, 목마름 가득, 뚫고 지나가지 못함
- [ ] C6 목이 마른 채로 할머니에게 말 걸면 **식혜** (하루 한 번)
- [ ] C7 장날(5일마다): 노점, 흥정 할아버지, 장구·꽹과리가 음악에 더해지는지

## D. 이웃 (품앗이·새참·마실)

- [ ] D1 동수 아저씨 화덕, 이장님 연탄, 미나 낚시 → 썰매 (얼음 위)
- [ ] D2 저녁 6시 뒤: 이웃이 평상·의자로 옮겨 앉음 → E → 앉기 → 끝나면 제자리, 시간 +1 (이장님은 회관 난롯가)
- [ ] D3 동수 아저씨 편지 장 (버튼 두 번 → 편지 화면)
- [ ] D4 할머니 새참: 된장찌개 들고 말 걸기

## E. 밤과 소리

- [ ] E1 17시쯤 노을 → 21시 밤까지 서서히 어두워짐. **정보창·단축칸·대화창은 안 어두워짐**
- [ ] E2 밤에 집 창호지, 전봇대 보안등, 장터 가게 문 불빛 / 불 땐 날 아궁이 불이 일렁임
- [ ] E3 걸을 때 화면 가장자리가 비거나 불빛 띠가 떨리지 않는지
- [ ] E4 저녁에 음악이 잦아들고 밤에는 바람 소리만, 가끔 먼 개 짖는 소리 / 아침 까치, 새벽 닭
- [ ] E5 집·가게 안은 밤에도 어둡지 않고 따뜻한 빛
- [ ] E6 ESC 메뉴에서 음악·효과음 볼륨이 먹히는지, 예전 Farm Country 곡이 안 나오는지

## F. 절기

- [ ] F1 5일째 방송 → 방앗간 안 팥죽 솥 E 세 번 → 7일째 팥죽 다섯 그릇 → 이웃 넷 + 마당 대문
- [ ] F2 9일째쯤 "봄이 문 앞에" + 대보름 날 (12일째쯤)
- [ ] F3 남쪽 논 달집에 나무 쌓기 → 대보름 아침 미나와 부럼 ("딱!")
- [ ] F4 밤 7시 이웃이 달집 둘레에 → **풍물 음악** → 쥐불놀이 (불빛이 따라 돎) → 달집 불 (화르륵, 마당이 밝아짐) → 보름달 그림 → 태울 것, 소원지
- [ ] F5 다음 아침 **봄** (큰 색 물결). Demo Mode면 데모 끝 네 장

## G. 봄 이후 (Demo Mode 꺼 두었을 때)

- [ ] G1 봄 첫 아침: 세상 색이 한 칸 돌아오고, 뒷산 길이 열리는지
- [ ] G2 생활 일지(J)에 "여름까지 약 N일"
- [ ] G3 **F1** 누르면 다음 계절로 (봄 → 여름 → 가을), 여름에 저수지, 가을에 노을 언덕이 열리는지
- [ ] G4 저장하고 껐다 켜서 이어지는지 (저장 폴더에 `save.json`과 `save.json.bak`)

## H. 봄 (F-1, Demo Mode 꺼 두고. 겨울을 건너뛰려면 F1)

- [ ] H1 봄 첫 아침: 논이 갈아엎은 흙, 뒷산 덤불에 분홍 진달래, 일지(J)에 "모내기(N일째)가 지나면 여름"
- [ ] H2 봄 3일째 방송 → 4일째: 큰 논 위 물꼬에서 E 세 번 → 논에 물이 차오르는 그림, 그날 밤 개구리 소리
- [ ] H3 마당 모판(우물 왼쪽): E로 볍씨 → 물뿌리개로 하루 한 번 → 며칠 뒤 초록 모
- [ ] H4 봄 7일째 10~16시 뒷산 옹달샘: 이웃들과 솥뚜껑, E → 화전 → 마지막 한 장 고르기 → 그 이웃이 다음에 고마워함
- [ ] H5 행복슈퍼 안 계산대에 명숙 아주머니: 말 걸면 (할 얘기 없을 때) 장 보기 창, 찹쌀가루·고추 모종
- [ ] H6 이웃 봄 이야기: 할머니 봄나물 무침, 동수 아저씨 답장(저녁), 미나 도토리(뒷산 빈터에 심기), 이장님 새참, 명숙 아주머니 보리차
- [ ] H7 봄 19일째 큰 논: 못줄과 이웃들 → E 여섯 번 → "올해 나에게 키우고 싶은 것" → 새참 → 모 심은 논 그림 → 다음 아침 여름
- [ ] H8 진달래 화전 만들기 (찹쌀가루 1 + 진달래 2), 고추 모종 심기 → 홍고추
