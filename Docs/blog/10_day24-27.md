### 🛠️ 주요 구현 기능 및 코드

#### 저장과 복원 (CropManager.cs)

```csharp
void Start()
{
    if (DataManager.instance.farmCropData.Any())
    {
        foreach (var crop in FindObjectsOfType<Crop>())
            if (crop != null) Destroy(crop.gameObject);

        foreach (var data in DataManager.instance.farmCropData)
        {
            GameObject cropGO = Instantiate(cropPrefab, data.position, Quaternion.identity);
            cropGO.GetComponent<Crop>().LoadData(data);
        }
    }
}

public void SaveCropData()
{
    DataManager.instance.farmCropData.Clear();
    foreach (var crop in FindObjectsOfType<Crop>())
    {
        DataManager.instance.farmCropData.Add(crop.GetData());
    }
}
```

#### 작물이 자기 상태를 내보내고 받기 (Crop.cs)

```csharp
public CropData GetData()
{
    return new CropData(transform.position, currentGrowthStage, isWatered);
}

public void LoadData(CropData data)
{
    transform.position = data.position;
    currentGrowthStage = data.growthStage;
    isWatered = data.isWatered;
    // ...
}
```

### 🚨 마주친 문제 및 해결 과정

**1. 돌아오면 작물이 여전히 사라짐 (Day 24)**
- 원인: 로그를 따라가 보니, Market과 Home 씬에도 `CropManager`가 실수로 들어 있었다. 이 '가짜 관리인'이 떠날 때 **작물이 0개인 빈 데이터로 덮어썼다.**
- 해결: 농장 관리인은 Farm 씬에만 있어야 한다. 다른 씬의 `CropManager`를 모두 지웠다.

**2. 다중 작물 시도의 시행착오 (Day 27)**
- `[CreateAssetMenu]`를 달았는데 Create 메뉴에 항목이 안 나왔다.
  - 원인: 다른 스크립트에 남아 있던 컴파일 에러가 에디터 갱신 자체를 막고 있었다.
- `Crop.cs`를 고치다 중괄호 짝이 어긋나서 함수들이 클래스 밖으로 밀려났다.
- `GetData()`는 작물 이름까지 저장하려 하는데 `CropData`에는 이름 칸이 없어서 인자 개수가 안 맞았다.

**3. 롤백 결정**
- 에러를 하나 고치면 둘이 나왔다. 코드가 필요 이상으로 복잡해지고 있다고 판단했다.
- 그래서 `Crop.cs`와 `PlayerAction.cs`를 Day 26 버전으로 되돌리고, 다중 작물은 나중에 다시 하기로 했다.
