### 🛠️ 주요 구현 기능 및 코드

#### 인트로 (IntroManager.cs)

```csharp
public class IntroManager : MonoBehaviour
{
    public Button startButton;

    void Start()
    {
        if (startButton != null)
        {
            startButton.onClick.AddListener(CloseIntro);
        }
        Time.timeScale = 0f; // 인트로 동안 게임 정지
    }

    void CloseIntro()
    {
        Time.timeScale = 1f;
        this.gameObject.SetActive(false);
    }
}
```

#### 게임 오버 (DataManager.cs)

```csharp
public void GameOver()
{
    if (gameOverPanel != null) gameOverPanel.SetActive(true);
    Time.timeScale = 0f;

    PlayerAction player = FindObjectOfType<PlayerAction>();
    if (player != null) player.enabled = false;
}
```

`Awake()`에 `Time.timeScale = 1f;`도 넣었다. 그래야 재시작했을 때 시간이 멈춘 채로 남지 않는다.

### 🚨 마주친 문제 및 해결 과정 (Day 31)

**1. 농사 기능이 없는 씬에서 클릭하면 멈춤**

- 원인: `PlayerAction`이 Home 씬에 없는 Tilemap을 쓰려 하거나, `MainCamera` 태그가 없는 카메라를 못 찾았다.
- 해결: 씬이 열릴 때마다 Tilemap을 새로 찾고(없으면 null로 두고 건너뜀), `Camera.main`이 없으면 `FindObjectOfType<Camera>()`로 한 번 더 찾게 했다.

**2. 씬을 옮기면 상단 UI가 멈춤**

- 원인 1: DataManager가 Farm 씬의 (이미 파괴된) UI를 계속 가리켰다.
- 원인 2: 씬에 Canvas가 두 개 있어서 `FindObjectOfType<Canvas>()`가 엉뚱한 Canvas를 잡았다.
- 해결: 씬이 열릴 때마다 **이름으로** UI를 다시 찾게 하고, 남는 Canvas를 지워 Canvas를 하나로 합쳤다.

**3. 부딪히면 플레이어가 빙글빙글 돈다**

- 해결: Rigidbody 2D → Constraints → **Freeze Rotation Z** 체크.

**4. 체력이 0이 돼도 안 끝난다**

- 해결: 위의 `GameOver()`를 만들었다.

### 📝 시즌 1 회고

33일 동안 **농사, 시간, 낮밤, 상점, 집, 보관함, 핫바, 미니게임, 인트로**까지 들어간 실행 파일을 만들었다.

돌아보면 가장 많이 배운 건 기능이 아니라 버그였다.

- **참조는 생명선이다.** 인스펙터의 빈칸, 지워진 스프라이트, 다른 타일 에셋 하나가 기능을 멈춘다.
- **살아남는 객체는 죽는 객체를 기억하면 안 된다.** `DontDestroyOnLoad`와 `sceneLoaded`는 이 프로젝트에서 가장 많이 쓴 단어다.
- **크게 넣지 말고 작게 넣자.** Day 27 롤백이 가르쳐 준 것.

그리고 솔직하게 남겨 둔 숙제도 있었다.

- 무슨 씨앗을 심어도 당근이 나온다.
- 흥정을 반복하면 골드가 무한히 나온다.
- 씬을 다녀오면 갈아 둔 땅과 물 준 땅은 초기화된다.
- 그림은 대부분 Piskel로 급하게 그린 임시 그림이다.

그리고 이 프로젝트는 여기서 1년 동안 멈췄다.
