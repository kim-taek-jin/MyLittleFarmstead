## 🎮 [Project Survival] 개발 일지 #5 - 자연의 메아리, 그리고 농사의 첫 삽 (Day 5~7)

날짜: 2025년 9월 27일 ~ 9월 30일

이번 편의 목표: 나무를 베고 돌을 캐는 단순한 채집에 '발견하는 재미'를 더하고, 이 게임의 중심이 될 **농사 시스템**의 첫 단계(땅 갈기 → 씨앗 심기)까지 만든다.

---

### 📝 개발 내용 요약

**Day 5 - '자연의 메아리' 시스템**

- 나무에서는 **햇살의 파편(Sunshine Shard)**, 돌에서는 **대지의 숨결(Earth's Breath)** 처럼, 평범한 자원에 깃든 특별한 아이템을 낮은 확률로 발견하는 시스템을 기획했다.
- 자원을 캘 때 `Random.Range()`로 확률(기본 10%)을 굴려서, 당첨되면 특별 아이템을 인벤토리에 넣었다.
- 일반 자원(Wood, Stone)과 따로 보이도록 **특별 아이템 전용 UI 패널**을 만들었다.

**Day 6 - 농사 시스템의 첫 삽**

- 농사 도구인 **괭이(Hoe)** 와, 자연의 메아리를 재료로 쓰는 강화판 **풍요의 괭이(Fertile Hoe)** 제작법을 추가했다.
- 단색 배경이던 월드를 **타일맵(Tilemap)** 으로 바꿨다. '일반 땅'과 '경작된 땅' 타일을 만들고, 타일 팔레트로 밭을 직접 그렸다.
- 괭이를 들고 땅을 클릭하면 '일반 땅'이 '경작된 땅'으로 바뀌는 `PlayerAction.cs`를 작성했다. 이 행동에도 에너지가 든다.

- 테스트하기 쉽게 게임 시작 때 **당근 씨앗**과 괭이를 지급했다.

### 🛠️ 주요 구현 기능 및 코드

#### 1. 확률로 '발견'하기 (ResourceCollector.cs)

인스펙터에서 확률을 바로 조절할 수 있게 `specialItemDropChance`를 public으로 열어 두었다.

```csharp
public float specialItemDropChance = 10f;

private void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Wood"))
    {
        if (dataManager.UseEnergy(10f))
        {
            Destroy(other.gameObject);
            dataManager.AddItem("Wood");

            if (Random.Range(0f, 100f) < specialItemDropChance)
            {
                dataManager.AddItem("Sunshine Shard");
                Debug.Log("✨ 반짝! 햇살의 파편을 발견했습니다!");
            }
        }
    }
    // Stone → Earth's Breath 도 같은 구조
}
```

#### 2. 특별 아이템 UI (DataManager.cs)

- `UpdateSpecialItemUI()`가 인벤토리를 돌면서 Wood, Stone 같은 일반 자원을 **제외한** 아이템만 슬롯으로 만들어 패널에 보여 준다.
- `AddItem`, `RemoveItem`이 불릴 때마다 함께 새로고침된다.

#### 3. 클릭한 타일로 행동 나누기 (PlayerAction.cs)

- 처음에는 `tile.name`으로 비교했는데 불안정했다. 그래서 **타일 에셋 자체를 변수로 연결해서 비교**하는 방식으로 바꿨다.

```csharp
Vector3Int cellPos = groundTilemap.WorldToCell(mouseWorldPos);
TileBase currentTile = groundTilemap.GetTile(cellPos);

if (currentTile == dirtTile) TryToTill(cellPos);          // 땅 갈기
else if (currentTile == tilledDirtTile) TryToPlant(cellPos); // 씨앗 심기
```

### 🚨 마주친 문제 및 해결 과정

**1. 기본 Tile 에셋을 만드는 메뉴가 없었다 (Day 6)**

- 원인: Unity 버전이나 패키지 설정 문제로 보였다. 2D 패키지끼리 의존성이 얽혀서 재설치도 어려웠다.
- 해결: **Rule Tile**을 만들고 Default Sprite만 지정해서 기본 Tile처럼 썼다. 메뉴에 직접 항목을 추가하는 커스텀 스크립트(`BasicTile.cs`)도 시도해 봤다.

**2. 제작(Craft) 버튼이 안 눌렸다 (Day 6)**

- 원인이 세 가지였다.
  1. UI를 클릭하면 그 클릭이 게임 월드까지 전달되는 **클릭 스루** 현상
  2. Vertical Layout Group의 Spacing이 -11이라 UI끼리 겹쳐서 클릭을 가로챔
  3. 코드는 `Wood`, 레시피 에셋은 `wood` → **대소문자 불일치**로 재료가 없다고 판단
- 해결:
  1. `EventSystem.current.IsPointerOverGameObject()`로 UI 위 클릭은 월드에 전달하지 않음
  2. Spacing 값을 고쳐서 겹침 제거
  3. `Debug.Log`로 판단 과정을 찍어 보고 레시피 이름을 정확히 고침

**3. 괭이로 클릭해도 타일이 안 바뀌었다 (Day 6)**

- 원인: 타일 팔레트의 **타일 에셋**이 아니라 **스프라이트**로 땅을 칠해서, 스크립트가 타일을 못 찾고 null을 받았다.
- 해결: 위에서 말한 대로 타일 에셋을 직접 비교하도록 바꾸고, 올바른 타일 에셋으로 땅을 다시 칠했다.

**4. UI 텍스트가 여러 줄로 쪼개지거나 겹쳤다 (Day 7)**

- 원인: 부모 패널의 Vertical Layout Group과 자식 슬롯의 Layout Element, Content Size Fitter 설정이 서로 충돌했다.
- 해결: 역할을 나눴다.
  - 자식(슬롯): "내 글자 길이에 맞춰 내 크기를 정할게" (Content Size Fitter + Layout Element)
  - 부모(패널): "너비는 내가 맞출 테니, 높이는 너희가 정해" (Child Controls Size 조절)
