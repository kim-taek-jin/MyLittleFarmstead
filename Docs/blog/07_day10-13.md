### 📝 개발 내용 요약

**Day 10 - 시간 시스템 뼈대**

- 시간 전체를 관리하는 `GameTimeManager`를 만들어 기존 `GameManager` 오브젝트에 붙였다.
- `Update()`와 `Time.deltaTime`으로 분 → 시 → 일이 자동으로 올라간다.
- 현실 1초에 게임 시간이 몇 분 흐를지 `minutesPerSecond`로 인스펙터에서 조절할 수 있게 했다.
- 콘솔에 "현재 시간: 1일차 09:30"처럼 찍어서 확인했다.

**Day 11 - 낮과 밤 (동적 조명)**

- `LightingManager`를 만들고, Unity의 **Gradient**로 하루 색을 정했다.
  - 자정: 남색 / 일출: 주황 / 정오: 흰색 / 일몰: 붉은색
- 하루 중 몇 %가 지났는지 계산해서 `Gradient.Evaluate()`로 색을 뽑고, 조명과 카메라 배경색에 넣었다.

### 🛠️ 주요 구현 기능 및 코드

#### 1. 시간에 따라 색 바꾸기 (LightingManager.cs)

```csharp
void Update()
{
    if (gameTimeManager == null) return;

    float timePercent = (gameTimeManager.hour + gameTimeManager.minute / 60f) / 24f;
    Color currentColor = lightColor.Evaluate(timePercent);

    directionalLight.color = currentColor;
    if (mainCamera != null)
    {
        mainCamera.backgroundColor = currentColor;
    }
}
```

#### 2. 포털 (Portal.cs)
지금 보면 정말 짧은데, 이 몇 줄이 게임을 여러 장소로 넓혀 줬다.

```csharp
public class Portal : MonoBehaviour
{
    public string destinationSceneName;

    private void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Player"))
        {
            SceneManager.LoadScene(destinationSceneName);
        }
    }
}
```

### 🚨 마주친 문제 및 해결 과정

**1. Directional Light를 못 찾음 (Day 11)**

- 현상: `LightingManager`에서 NullReferenceException
- 원인 후보: GameManager가 프리팹이거나, 씬 저장 누락, 매니저 중복 등 여러 가지가 의심됐다.
- 해결: 인스펙터 연결에 기대지 않고, `Start()`에서 `FindObjectOfType<Light>()`로 코드가 직접 찾게 했다.

**2. 정오 이후로 색이 안 바뀜 (Day 11)**

- 현상: 새벽 주황 → 낮 흰색까지는 되는데, 저녁과 밤이 안 온다.
- 원인: `Debug.Log`로 시간 비율과 색을 찍어 보니, 코드는 멀쩡했고 **Gradient의 75%, 100% 키 색이 흰색으로 잘못 들어가 있었다.**
- 해결: 그라데이션 편집기에서 두 키를 노을색과 밤색으로 다시 지정했다.
- 교훈: 코드만 의심하지 말 것. 데이터(에셋 설정)가 틀린 경우도 많다.

**3. 씬을 옮기면 플레이어가 사라짐 (Day 13)**

- 원인: `SceneManager.LoadScene()`은 기본적으로 이전 씬의 오브젝트를 전부 파괴한다.
- 해결: `Awake()`에 `DontDestroyOnLoad(this.gameObject)`를 넣고, 싱글턴(`static instance`)으로 되돌아올 때 플레이어가 둘이 되는 것도 막았다.

**4. 포털이 한쪽으로만 됨 (Day 13)**

- 현상: Farm → Market은 되는데 Market → Farm이 안 된다.
- 원인: Market 쪽 포털의 Box Collider 2D에 **Is Trigger**가 꺼져 있어서 벽처럼 동작했고, `OnTriggerEnter2D`가 불리지 않았다.
- 해결: Is Trigger 체크. 체크박스 하나였다.
