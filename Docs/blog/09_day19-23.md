### 🛠️ 주요 구현 기능 및 코드

#### 핫바 선택 (Hotbar.cs, Day 22)

```csharp
void Update()
{
    if (Input.GetKeyDown(KeyCode.Alpha1)) SelectSlot(0);
    if (Input.GetKeyDown(KeyCode.Alpha2)) SelectSlot(1);
    if (Input.GetKeyDown(KeyCode.Alpha3)) SelectSlot(2);
    if (Input.GetKeyDown(KeyCode.Alpha4)) SelectSlot(3);
    if (Input.GetKeyDown(KeyCode.Alpha5)) SelectSlot(4);
}

void SelectSlot(int index)
{
    if (index < 0 || index >= slots.Count) return;

    slots[selectedSlotIndex].transform.Find("Selector").gameObject.SetActive(false);
    selectedSlotIndex = index;
    slots[selectedSlotIndex].transform.Find("Selector").gameObject.SetActive(true);
}
```

### 🚨 마주친 문제 및 해결 과정

**1. Home 씬에서 클릭하면 게임이 멈춤 (Day 19)**
- 원인: Home 씬 카메라에 `MainCamera` 태그가 없어서 `Camera.main`이 null이었다.
- 해결: 카메라에 태그 설정.

**2. "Scene 'Home' couldn't be loaded" (Day 19)**
- 원인: Build Profiles의 Scene List에 Home을 넣지 않았다.
- 해결: 목록에 드래그 앤 드롭으로 추가.

**3. 플레이어가 침대 위에 그려짐 (Day 19)**
- 원인: 두 스프라이트의 그리기 순서가 정해져 있지 않았다.
- 해결: 일단 플레이어의 `Order in Layer`를 높여 임시 처리. (나중에 Y축 기준 자동 정렬로 바꿀 예정)

**4. Home 씬 버그가 계속 안 잡힘 → 계획 수정 (Day 20~21)**
- 상황: Home 씬에서 클릭하면 NullReferenceException이 계속 났고, 이걸 잡느라 일정이 밀렸다.
- 결정: 이 버그는 장기 과제로 두고, **보관함을 Home 대신 안정적인 Farm 씬에 먼저** 만들기로 했다.
- 결과: 보관함 기능을 제때 완성했다. 버그를 못 잡는 날에는 "어디서 만들지"를 바꾸는 것도 방법이었다.

**5. 핫바 슬롯 안의 아이콘과 글자를 못 찾음 (Day 23)**
- 원인: `HotbarSlot` 프리팹에 스크립트를 붙인 뒤, 그 안의 public 변수(Icon, ItemCountText)를 연결하지 않았다. Hierarchy에서 프리팹을 지워 버려서 어디서 연결해야 할지도 헷갈렸다.
- 해결: Project 창에서 프리팹을 **더블클릭해 프리팹 편집 모드**로 들어가면, 프리팹 내부 Hierarchy를 보면서 연결할 수 있다는 걸 배웠다.
