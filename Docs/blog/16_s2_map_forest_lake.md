## 🌱 [My Little Farmstead] 개발 일지 #16 - 농장을 4배로 넓히고, 회색 숲과 회색 호수를 되살리다

날짜: 2026년 11월

이번 편의 목표: 한 화면짜리 농장을 **화면 4장 크기**로 넓히고, 마음의 계절이 올 때마다 새 지역이 열리게 한다.
- 겨울: 넓어진 농장 + 묵은 밭 개간
- 봄: 숲
- 여름: 호수

---

### 📝 1. 맵을 '글자'로 만들기

맵을 Unity 에디터에서 손으로 칠하지 않고, **한 글자 = 한 칸**인 텍스트 지도로 만든다 (`Assets/Resources/Maps/farm.json`).

```
.  잔디   =  길   x  빈 흙   g  잡초   k  그루터기   o  바위
T  나무   r  돌   a  사과   *  꽃     ~  예전 농장(그대로 둠)
```

- 이 파일 하나를 **게임 코드(`MapData.cs`)와 그림 스크립트(`farmmap.py`)가 같이 읽는다.** 그래서 바닥 그림과 충돌 판정이 어긋나지 않는다.
- 출구(`exits`)에는 그 길을 여는 계절(`locked`)과 잠겼을 때/열렸을 때 그림(`art`, `openArt`)을 적는다.
- 예전 농장은 북서쪽에 **같은 좌표 그대로** 두었다. 그래서 시즌 1의 밭, 집, 우물, 흥정 문이 전부 그대로 동작한다.
- `farm.json`을 지우면 예전 한 화면 농장으로 돌아간다.

```csharp
[Serializable]
public class MapExit
{
    public string to;
    public float x0, y0, x1, y1;
    public string locked;   // 이 출구를 여는 마음의 계절 (비어 있으면 열림)
    public string sign;     // 잠겨 있을 때 보여줄 말
    public string art;      // 잠겨 있을 때 그림 (기본: 가시덤불)
    public string openArt;  // 열린 뒤 그림 (기본: 꽃 아치)
    ...
}
```

### 📝 2. 넓어진 농장과 개간
- 남동쪽에 **묵은 밭**(18×7칸)이 생겼다. 잡초 65개, 그루터기 15개, 바위 10개.
- 잡초는 낫, 그루터기와 바위는 곡괭이로 치운다. 전부 치우려면 며칠이 걸린다. 치운 칸은 저장되고, 다 치우면 마음 +5.
- 카메라가 플레이어를 따라가고, **픽셀 격자(1/32칸)에 맞춰 움직여서** 그림이 떨리지 않는다.
- 서쪽 숲길, 남쪽 언덕길, 남동쪽 호숫길은 회색 가시덤불(호수는 회색 갈대)이 막고 있다. 부딪히면 표지판이 "봄이 오면..." 같은 말을 한다.

### 📝 3. 봄: 회색 숲

마음이 **30(봄)** 이 된 다음 아침, 가시덤불이 **꽃 아치**로 바뀌며 숲이 열린다.

- 숲은 짙은 회색으로 시작한다.
- 빈터의 조약돌 원에 **도토리**를 심고 물을 주면, 도토리 → 새싹 → 묘목 → 어린 참나무로 자란다.
- 어린 참나무가 되면 **그 빈터 둘레만 색이 돌아온다.** 세 곳을 모두 살리면 가운데 큰 나무가 깨어나 꽃을 피우고, 숲 전체가 컬러가 된다.
- 아침마다 봄나물(달래, 고사리, 곰보버섯)이 돋고, 샘가 그루터기에서 쉬면 마음이 오른다.

**구현:** 같은 숲을 회색 그림과 컬러 그림 두 장으로 그려 겹치고, 컬러 그림은 **SpriteMask** 안에서만 보이게 했다. 마스크 가장자리는 둥근 디더링이라 픽셀 아트답게 번진다.

### 📝 4. 여름: 회색 호수

마음이 **60(여름)** 이 된 아침, 회색 갈대가 초록으로 살아나 갈라지며 호숫길이 열린다.

- 호수는 흐린 회색이다. 서쪽 돌계단에서 **잡은 물고기를 놓아주면** 호수가 맑아진다.
- 맑기 10 / 25 / 45를 넘을 때마다 서쪽 만 → 가운데 → 동쪽 만 순서로 색이 돌아오고, 다 맑아지면 **밤마다 반딧불이**가 떠오른다.
- **물고기를 팔면 돈, 놓아주면 호수가 되살아난다.** 플레이어가 고른다.
- 호수에서만 낚이는 물고기: 블루길, 밤에만 나오는 문핀, **물이 맑아야 보이는 유리고기.**

```csharp
// 물고기마다 맑기 점수 (놓아줄 수 없는 것은 0)
public static int Points(string fish)
{
    switch (fish)
    {
        case "Minnow": return 1;
        case "Carp": return 2;
        case "Bluegill": return 2;
        case "Moonfin": return 3;
        case "Glassfish": return 4;
        ...
    }
}
```

### 🚨 마주친 문제와 결정

**1. 새 지역을 새 씬으로 만들지 않았다**
- 시즌 1에서 씬 전환 버그에 몇 주를 썼다. 그래서 숲(x 190~220), 호수(x 250~280)를 **Farm 씬 안 멀리** 실행 중에 만들고, 입구에 들어가면 순간이동 + 카메라 범위만 바꾸게 했다.
- 덕분에 매니저들이 참조를 잃는 문제가 원천적으로 사라졌다.

**2. "옛 기차역"을 계획에서 뺐다**
- 처음 계획에는 남쪽 길 끝에 "옛 기차역"이 있었다. 그런데 스타듀밸리의 철도 구역과 너무 비슷했다. 다리를 나무로 고쳐 길을 여는 아이디어도 같은 이유로 뺐다.
- 대신 **노을 언덕**으로 바꿨다. (다음 편)

**3. 괭이가 너무 많은 일을 했다**
- 처음엔 괭이로 그루터기, 바위까지 치웠다. 숲을 만들면서 **곡괭이**를 따로 만들고, 괭이는 땅 가는 일만 하게 했다. 숲 남쪽의 쓰러진 통나무도 곡괭이가 있어야 치울 수 있다.

**4. 규칙은 Unity 없이 테스트**
- `ForestState`, `LakeState`처럼 저장되는 상태와 규칙은 Unity에 의존하지 않는 순수 C# 클래스로 분리했다. 그래서 Unity 없이 "물고기 5마리를 놓아주면 몇 구역이 맑아지나" 같은 걸 바로 테스트할 수 있다.
